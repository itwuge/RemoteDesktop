## 3. 已知缺失项（按页面）

### 连接页
1. **码流与解码未接入**：`RemoteRenderer` 仅占位，不解 H.264/HEVC，画面容器显示「未接真实解码」。
2. **命令层未接入**：`ControlContract.WIRED = false`，`start_connection` 只做参数校验；校验通过后进入的是「离线预览」会话窗。
3. **本机设备 ID 为占位**：`ControlContract.localDeviceId()` 返回「待设备身份接入」，未做设备身份注册。
4. **最近连接恒为空态**：依赖 `list_sessions()`，未接入时只显示空态，不虚构记录。

### 设备页
5. **账号未登录**：无登录能力，设备列表为空态。
6. **同账号设备列表未接入**：`list_devices()` 未接线，故不展示任何示例设备。
7. **在线 / 离线 / 未知状态仅作图例**：无 presence 心跳数据源，真实状态恒为「未知」。
8. **免确认开关禁用**：未登录时不可修改（置灰并给出原因），且契约 `set_trust_policy` 是按设备粒度，UI 当前是列表级开关，需产品确认粒度。

### 消息页
9. **只有 1 条本地系统通知**（「预览版说明」），非后端下发；已读状态存本机 `SharedPreferences`。
10. **申请与审批、授权变更无数据源**：对应 `list_access_requests()` / `get_audit_log()` 未接线，只显示空态。
11. **未读数只统计内置那 1 条**，非真实未读聚合。

### 我的页
12. **账号体系缺失**：无注册 / 登录 / 登出，账号卡片为「未登录」。
13. **默认画质档为本机偏好**：只写 `AppPrefs`，不校验对端能力；会话内切换走 `apply_quality_profile`，同样未下发。
14. **自动降档开关不生效**：本地偏好，降级策略在命令层，未接入。
15. **剪贴板同步为示意**：不读写系统剪贴板，不落地明文（`SessionActivity` 内只更新状态文案与字节数）。
16. **诊断导出为本地生成**：脱敏文本经 SAF 写入用户选择的位置，不含命令层真实指标。

### 会话窗
17. **文件传输为本地示意进度**：不选择真实文件、不做分块 / 哈希 / 限速；未建立真实会话时按钮置灰。
18. **输入上行只到契约入口**：`injectInput` 仅留痕与校验，不产生真实上行；坐标映射为本地算法，未与真实画面校准。
19. **无横竖屏以外的自适应**：平板 / 折叠屏未单独适配；固定暗色主题，无浅色模式。
20. **进程被杀后只恢复 tab 与滚动位置**（本轮已补滚动位置），**不恢复会话本身**；会话窗不可恢复。

## 4. 模拟器受阻原因（实测）

- 宿主 `HypervisorPresent = False`；AEHD 未安装、WHPX 未启用、无 WSL2。
- 安装任一硬件加速组件都需要管理员权限并重启，属于本次任务约束之外，未执行。
- emulator 纯软件 TCG 路径三种参数组合（默认 cpu / `-cpu qemu64` / 关闭蓝牙与 Vulkan）均以 `0xC0000005` 崩溃，且崩溃早于 adb 上线。
- 崩溃上报进程 `crashpad_handler.exe` 自身异常退出，拿不到 qemu 崩溃模块与调用栈。
- **模拟器路线已确认不可行，后续不再投入时间**；改为按 `真机验证清单.md` 用真机取证。

## 5. 契约缺口回报（未改契约正文）

以下为界面落地需要、但 `desktop-v1` 未明确的部分，按现状先本地处理，等契约补充：

1. **消息中心聚合缺命令**：契约有 `list_access_requests(direction)`、`get_audit_log`、`get_wall_audit_log`，但没有把「申请与审批 + 授权变更 + 系统通知」聚合成一个消息流、也没有未读计数与「全部已读」命令。当前安卓侧只能本地造 1 条系统通知。
2. **本机设备身份缺只读命令**：连接页要展示本机 ID，但契约里 `start_hosting` / `refresh_access_code` 属于被控侧，控制端不应调用；缺一个只读的 `get_local_device_id` 类命令。
3. **`list_sessions` 每项字段未定义**：契约只写 `data = {"items": list}`，未规定 item 结构，安卓侧无法确定「最近连接」要渲染哪些字段。
4. **免确认开关粒度不明**：`set_trust_policy(device_id, require_confirm)` 是逐设备，而设备页 UI 通常是一个列表级开关，需要明确是逐设备还是全局默认。
5. **默认画质档无命令**：契约只有会话级 `apply_quality_profile`，没有「新建会话默认档」的读写命令；当前存在本机偏好里。
6. **诊断导出无命令**：当前由客户端本地生成脱敏文本，不经过命令层；若后续要求导出真实指标，需要契约补命令。
