## 4. 缺陷记录

### D1（P0，已修复）：打开会话窗必崩

- 复现路径：冷启动 App → 连接页 → 点「打开本机会话窗口（界面验证）」→ 立即闪退；系统提示「RDC 远程桌面因自身问题闪退」。复现 2 次，稳定。
- 崩溃栈：

```
java.lang.NullPointerException: Layout parameters cannot be null
    at android.view.View.setLayoutParams(View.java)
    at com.rdc.remote.SessionActivity.smallButton(SessionActivity.kt:660)
    at com.rdc.remote.SessionActivity.buildTransferCard(SessionActivity.kt:600)
    at com.rdc.remote.SessionActivity.buildPortraitBody(SessionActivity.kt:413)
    at com.rdc.remote.SessionActivity.buildViews(SessionActivity.kt:302)
    at com.rdc.remote.SessionActivity.onCreate(SessionActivity.kt:142)
```

- 根因：`smallButton()` 在 onCreate 阶段执行 `layoutParams = null`，`View.setLayoutParams(null)` 抛 NPE；`actionButton()` 存在同样写法，为同类隐患。
- 修复点（最小改动，未重构）：
  - `smallButton()`：`layoutParams = LinearLayout.LayoutParams(0, dp(30), 1f)`
  - `actionButton()`：`layoutParams = LinearLayout.LayoutParams(0, dp(39), 1f)`
  - 全文件检索 `layoutParams = null` 仅此两处，已全部清除；尺寸、边距、weight 语义与调用处 `smallParams` / `actionParams` 一致。
- 修复后结果：重新打包 0.2.1 / versionCode 3 并 `adb install -r`，冷启动进会话窗不再崩溃；`[page_ready]` → `[surface_created]` → 横屏 `[orientation_changed] state_kept=true` → 返回 `[back_to_portrait]` → `[session_stopped]` → `[page_destroyed]` 全链路正常，crash buffer 为空。
- 证据：`00-崩溃现场.png`、`crash-SessionActivity-repro.txt`、`session-fixed-logcat.txt`、`session-orientation-logcat.txt`、`07`/`08`/`09` 截图。

### D2（P2，未修复）：横屏滚动位置在旋转往返后归零

- 复现路径：底部「我的」→ 横屏 → 上滑到底（13，可见「诊断导出（脱敏）」「关于」「版本 0.2.1」）→ 转竖屏 → 再转横屏 → 回到顶部（14，显示「未登录」「默认画质」）；「连接」页同样复现（15 → 16）。
- 期望行为：横→竖→横往返后保持进入前的滚动位置，至少不跳回顶部。
- 实际行为：竖屏下页面内容未超出视口，ScrollView 最大滚动量为 0，被夹到 0 后无法恢复；MainActivity 未保存/恢复滚动偏移。

### 9.1 实现与契约对照

| 项 | 实现 | 契约依据 |
|---|---|---|
| 注册 | `RdcAccount.register(name, password)` → `account_id`、`created_at` | desktop-v1 §3.2 第 14 条 |
| 登录 | `RdcAccount.login(name, password)` → `account_id`、`device_token`、`session_token`、`expires_at` | desktop-v1 §3.2 第 15 条 |
| 退出 | `RdcAccount.logout()` → `account_id`、`status`、`revoked_at`、`kicked_sessions` | desktop-v1 §3.7 第 43 条 |

| 账号规则 | 3 至 64 位 `[A-Za-z0-9_.@-]`；口令至少 8 位 | `src/rdc/accounts/store.py` |

- 口令：PBKDF2-HMAC-SHA256，200000 次，16 字节随机盐；只存 salt 与派生值，不存明文，也不写日志。
- 令牌：设备令牌与会话令牌各 32 字节随机数；只存设备令牌的 SHA-256 摘要。会话令牌 15 分钟、登录态 30 天，与 `store.py` 的 `SESSION_TOKEN_TTL_SECONDS`、`DEVICE_TOKEN_TTL_SECONDS` 一致。
- 登录态：应用私有 SharedPreferences `rdc_accounts`；杀进程重开由 `RdcAccount.session()` 读回，退出登录清空账号会话四个键。
- 定位：本机本地账号，不跨设备同步；账号页与「我的」页均有说明，避免"登录后能看到其他设备"的误解。
- 口径核对：同一口令/盐/迭代次数下，JDK 17 `PBKDF2WithHmacSHA256` 与 Python `hashlib.pbkdf2_hmac('sha256')` 输出一致（`cb00d622…f872e2`），派生策略与桌面端相同。
