中继策略

apply_relay_policy(endpoint, egress_mbps, degrade_profile)

仅本机管理员可用。出口带宽与降级档写配置，不写协议常量；预算由 RelayPolicy 计算。

中继固定四档：L0 1280×720@30 / 2000kbps，L1 960×540@30 / 1200kbps，L2 640×360@20 / 600kbps，L3 仅音频级保活 / 200kbps。任何中继档都不提供 4K60，界面须明示「中继模式已降级」。失败码：POLICY_INVALID、RELAY_UNREACHABLE。
