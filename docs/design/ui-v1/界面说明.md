# RDC 远程桌面 · 界面说明（ui-v1）

| 项 | 内容 |
|---|---|
| 产物 | `docs/design/ui-v1/index.html`（单文件、自包含、可点击原型） |
| 说明文档 | `docs/design/ui-v1/界面说明.md` |
| 阶段 | PoC 骨架阶段的界面设计稿，不代表功能已实现 |
| 依据 | `docs/contracts/desktop-v1.md` v1.5 共 47 个命令；原型覆盖第 1 至 40 条，第 41 至 47 条（直接授权、转授、登出、主动吊销、退回全预览、墙审计、预览令牌）待界面接入 |
| 视觉 | 深色默认、可切换浅色；系统字体栈；无图片资源；界面元素与远端画面均由 CSS / 内联 SVG 绘制 |

> **边界声明：界面不承载业务逻辑，只做参数收集、状态呈现与命令调用。**
>
> 界面不发起网络、不解析协议、不做设备发现，不做画质决策、自动降级、重试或通路选择，不生成或改写错误码与 `message`。所有设备码、连接码、指标、时长、权限状态均为示意占位；所有真实状态、指标与错误都必须来自 `desktop-v1` 命令返回值。
>
> 全屏、工具栏收放、深浅色、安卓横竖屏、软键盘与画质面板展开均为**视图状态**，不产生命令。

**命名校正**：任务描述中举例的 `connect`、`start_session`、`set_quality_profile` 在 v1 契约中**不存在**。本稿严格使用契约中的 `start_connection`、`apply_quality_profile`；连接任务完成后直接进入会话，没有 `start_session` 命令。

---

## 1. 打开方式与原型结构

双击 `index.html` 即可在浏览器中打开，无外部 CDN、无外部字体、无图片请求。全部页面切换、主题切换、横竖屏切换、工具栏与画质面板均由内联 JavaScript 完成。

顶部工具条：

- **桌面端 / 安卓控制端**：切换两套端形态。
- **示意数据 · 界面不承载业务逻辑**：固定提示。
- **切换浅色 / 切换深色**：两套主题 token，默认深色。

桌面端左侧栏 7 个入口（主界面、会话窗口、屏幕墙、设置、登录 / 注册、设备列表、申请与审批），共 10 个页面（含连接中、连接失败、连接被拒三个状态页）；桌面窗口右上角的 Windows / macOS / Linux 仅切换窗口装饰（标题栏、交通灯与圆角），信息架构一致。安卓端顶部 7 个页面入口（连接页、会话竖屏、会话横屏、账号登录、设备列表、申请审批、权限引导），会话可在竖屏与横屏之间切换。

## 3. 逐页说明与命令对应

### D1 桌面 · 主界面

**界面内容**

- 本机设备码与临时连接码，带「仅本机可见」与失效倒计时（示意）。
- 「启动被控 / 停止被控」「刷新口令」「设置」。
- 对方设备码 + 临时连接码输入框、「连接」按钮、记住设备勾选。
- 最近会话列表，显示通路（直连 / 中继 L1）与档位。

**命令对应**

| 用户动作 | 调用命令 | 参数来源 / 说明 |
|---|---|---|
| 启动被控 | `start_hosting(display_name)` | 设备名由界面收集；返回 `device_id`、`access_code`、`expires_at`，界面只负责显示，不自行生成口令 |
| 停止被控 | `stop_hosting()` | 成功后清空/置灰连接码区域，不本地推算 |
| 刷新临时口令 | `refresh_access_code()` | 返回 `access_code`、`expires_at`；口令不写日志 |
| 点击「连接」 | `start_connection(device_id, access_code)` | 两个输入框收集参数；返回 `task_id`、`total`，随后进入 D4 |
| 最近会话 | `list_sessions()` | 列表内容来自 `data.items`，包括通路与档位 |
| 打开设置 | `open_settings()` | 按返回的 `data.section` 定位设置分区 |

> 原生「复制设备码」按钮在原型中只弹提示，不写系统剪贴板，也不产生命令。

### D2 桌面 · 会话窗口

**界面内容**

- 远端画面区域：CSS 绘制的桌面占位，标注「远端画面占位 · 数据示意」；无活动会话时覆盖「未连接」卡片，提供「发起连接」与「返回主界面」。
- 左上：对端设备、直连 P2P 标识。
- 右上：悬浮指标面板（画质档位、帧率、p50/p95 延迟、码率、切换次数）。
- 右侧会话侧栏：**文件传输**卡片与**剪贴板同步**卡片（窄屏下移到画面下方）。
- 底部：工具栏（全屏、画质、键盘、剪贴板、结束会话、收起工具栏）。
- 全屏后隐藏侧栏，顶部显示「Esc 退出」提示；工具栏可收起为「显示工具栏」胶囊。

**文件传输卡片**

- 文件选择入口、只读目标目录、当前文件、0–100% 进度条、速率、剩余时间。
- 暂停 / 继续 / 取消 / 失败重试；另有「模拟中断」用于演示失败重试（仅原型）。
- 拖拽进入远端画面时整块高亮并提示「松开以传输到远端」，离开恢复；松开后立即开始传输并提示「已开始传输：文件名」。
- 未连接时卡片提示「请先建立会话」，选择文件、暂停、继续、取消、重试均置灰；拖拽不开始传输，只提示未连接。

**剪贴板同步卡片**

- 开关默认开启；关闭后「同步本端文本」「从远端拉取」置灰，状态显示「同步已关闭」。
- 状态行显示最近一次内容类型、大小与时间；同步本端文本超过 256 KiB 时显示「已截断」，远端图片超过 4 MiB 时显示「已拒绝」。
- 仅做原型演示，不读取或写入系统剪贴板。

**命令对应**

| 用户动作 / 数据区域 | 调用命令 | 说明 |
|---|---|---|
| 进入会话 | `get_session_status(session_id)` | 读取 `state`、`transport_kind`、`quality_profile`、`peer_device_id`；`state` 不活跃时显示「未连接」 |
| 指标面板刷新 | `get_session_metrics(session_id)` | p50/p95、fps、bitrate、switches_used/limit、quality_events 均原样呈现，界面不计算 |
| 画质菜单选择 | `apply_quality_profile(session_id, profile)` | profile 取 `auto`、`4K60`、`1440p60`、`1080p60`、`1080p30`；成功回填 `quality_profile` |
| 结束会话 | `stop_session(session_id)` | 成功后回到主界面，会话状态置「未连接」 |
| 选择文件 / 拖拽落点 | `start_transfer(session_id, file_name, target_dir)` | 文件名与只读目标目录由界面收集；返回 `task_id`，随后轮询 `get_transfer_progress` |
| 进度、速率、剩余时间 | `get_transfer_progress(task_id)` | `transferred_bytes`、`total_bytes`、`rate_bps`、`eta_seconds`、`state` 原样呈现；原型每 400ms 演示推进 |
| 暂停 | `pause_transfer(task_id)` | 成功后状态置「已暂停」，停止推进 |
| 继续 | `resume_transfer(task_id)` | 成功后恢复推进，速率与剩余时间继续更新 |
| 取消 | `cancel_transfer(task_id)` | 状态置「已取消」，暂停 / 继续置灰 |
| 失败重试 | `start_transfer`（同一文件与目标目录） | `state=failed` 时重试回到「传输中」；真实实现以 `message` 为准 |
| 同步本端文本 | `push_clipboard(session_id, content_type, content)` | 文本上限 256 KiB，超出部分截断并提示「已截断」 |
| 从远端拉取 | `pull_clipboard(session_id)` | 图片上限 4 MiB，超出返回拒绝，界面显示「已拒绝」 |
| 剪贴板开关 | `set_clipboard_enabled(session_id, enabled)` | 关闭后同步按钮置灰；状态行显示「同步已关闭」 |
| 进入会话 / 打开剪贴板卡片 | `get_clipboard_status(session_id)` | 读取最近一次类型、大小、时间与启用状态 |
| 工具栏「剪贴板」 | 无（视图） | 定位并高亮侧栏剪贴板卡片，不弹死提示 |
| 全屏、工具栏收放、键盘 | 无（视图） | 键盘按钮因 v1.4 无桌面键盘命令而**置灰**，`title` 说明原因 |

**档位与通路表现**

- `auto` 起步 1080p60，稳定 10 秒后逐档回升；不直接以 4K60 起步。
- 4K60 仅 P2P；中继通路只有 L0–L3，界面固定显示「中继模式已降级」。
- 中继下请求 4K60 返回 `PROFILE_UNSUPPORTED`，界面恢复 `auto`，并原样展示命令 `message`。
- 指标面板中的 `switches_used / switches_limit` 只读展示；自动降级由会话层控制器执行。

### D3 桌面 · 设置

**界面内容**

- 画质档位：4K60、1440p60、1080p60、1080p30（地板）、auto。
- 自动降级策略：弱网自动降档、1080p30 地板、每会话总切换上限 6 次、同档位进入上限 2 次、回升条件 10 秒。
- 编码：硬件编码优先、首选编码器、软件兜底 ≤1080p30、关键帧 2 秒。
- 安全：临时码 5 分钟、首次连接本机确认、锁屏断开会话、指纹变化提示、固定口令。
- 中继策略：端点、出口带宽、降级档 L0–L3。

**命令对应**

| 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 进入设置 | `open_settings()` | 返回 `data.section`，界面据其定位 |
| 应用中继策略 | `apply_relay_policy(endpoint, egress_mbps, degrade_profile)` | 三个参数由界面收集；失败码 `POLICY_INVALID`、`RELAY_UNREACHABLE` 原样提示 |
| 选择默认画质档 | **v1 无对应写入命令** | 仅为偏好呈现。实际切换必须在会话内调用 `apply_quality_profile(session_id, profile)` |
| 硬件编码开关 | **v1 无对应命令** | 原型只呈现配置意图，不臆造编码配置命令 |
| 安全开关、固定口令 | **v1 无对应命令** | 原型只呈现选项；实际由配置层与会话层执行 |
| 自动降级各项 | **v1 无写入命令** | 规则来自设计书;界面呈现为说明与只读值 |

> 设置页的开关会在原型中切换视觉状态，但**不会**被写成已接入命令层。

### D4 桌面 · 连接中

**界面内容**

- 4 个阶段：设备与口令校验 → 协商会话密钥 → 建立传输通路 → 等待首帧。
- 进度条与 `completed / total` 计数、取消按钮；原型点击「连接」会演示 0→4 的进度，静态查看时为 2/4。

**命令对应**

| 用户动作 / 数据区域 | 调用命令 | 说明 |
|---|---|---|
| 轮询进度 | `get_connection_progress(task_id)` | 读取 `completed`、`total`、`status`、`cancelable`；status 取 pending/running/canceled/done/failed |
| 取消连接 | `cancel_connection(task_id)` | 使用同一个 `task_id`；失败码 `TASK_NOT_FOUND` 原样提示 |
| 完成后进入会话 | `get_session_status(session_id)` | 连接任务完成推进会话；**契约没有 `start_session`** |

### D5 桌面 · 连接失败

**界面内容**

- 错误图标、标题、`message` 原样展示、`error_code` 等宽显示。
- 失败阶段与 `task_id` 作为示意元数据。
- 「重新输入」回到主界面并聚焦设备码；「返回主界面」。

**命令对应**

| 数据 / 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 页面数据 | 展示最近一次 `CommandResult` | `message` 必须原样显示，界面不改写、不补写 |
| 示例错误 | `DEVICE_NOT_FOUND` | 契约口径：提示重新输入或刷新设备列表 |
| 重试 | `start_connection(device_id, access_code)` | 重新收集参数并发起；不在界面内做退避策略 |

### D6 桌面 · 连接被拒

**界面内容**

- 「连接被拒绝」标题，示例为 `ACCESS_CODE_INVALID`（口令错误或过期）。
- 展示已尝试次数与锁定策略（示意），提供「重新输入口令」。

**命令对应**

| 数据 / 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 页面数据 | 展示最近一次 `CommandResult` | `message` 原样呈现，不自行生成错误码 |
| 示例错误 | `ACCESS_CODE_INVALID` | 回到口令输入；`SESSION_BUSY`（对端已有会话或本机达上限）也可复用同一状态页版式 |
| 重试 | `start_connection(device_id, access_code)` | 参数来自输入框；本页不承载重试次数与锁定时长的业务逻辑 |

> 「失败 / 被拒」是界面状态页分组，不是契约错误码；具体原因始终来自 `error_code` 与 `message`。

### D7 桌面 · 登录 / 注册

**界面内容**

- 登录 / 注册两个页签，切换只改表单字段，不产生命令。
- 登录：账号 + 口令；注册：账号 + 口令 + 确认口令。
- 右侧说明卡片：一账号多设备、多账号经授权控制同一设备、同账号免确认默认开启。

**命令对应**

| 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 点击「登录」 | `login_account(account, password)` | 返回 `account_id`、`device_token`、`session_token`、`expires_at`；令牌不显示全文、不写日志 |
| 点击「注册并登录」 | `register_account(account, password)` | 成功后仍需 `login_account` 才有令牌 |
| 刷新会话令牌 | `refresh_session_token(device_token)` | 返回新的 `session_token` 与过期时间 |
| 去设备列表 | 无 | 页面跳转到 D8 |

> 原型对账号为空、口令少于 8 位、两次口令不一致做内联报错；校验通过才跳转 D8 并更新令牌状态。真实实现必须等命令返回 `ok=true` 才能进入，且 `message` 原样展示。未登录时「刷新会话令牌」置灰并带 `title` 说明。

### D8 桌面 · 设备列表

**界面内容**

- 每台设备显示名称、平台、归属（所有者 / 被授权）、通路、在线状态。
- 「免确认」为设备级开关：开启显示「免确认」，关闭显示「需审批」。
- 操作：连接、授权详情、绑定新设备、待审批入口。
- 「绑定新设备」展开内联表单：设备码 + 6 位数字连接码；非 6 位数字就地报错，成功后设备数 +1 并在列表新增一行。
- 「待审批」计数与审批页数量同步，批准 / 拒绝后递减。

**命令对应**

| 用户动作 / 数据区域 | 调用命令 | 说明 |
|---|---|---|
| 列表数据 | `list_devices()` | 每项含 `device_id`、`display_name`、`bound_at`、`online`、`require_confirm`、`owner` |
| 切换免确认 | `set_trust_policy(device_id, require_confirm)` | 变更进审计 `trust_policy.change`；界面只显示返回值 |

### D9 桌面 · 申请与审批

**界面内容**

- 两个页签：待我审批（incoming）、我发起的（outgoing）。
- 每条申请显示设备、申请人、范围、理由、状态。
- incoming 每条提供时限选择（30 分钟 / 2 小时 / 一次性）+ 批准 / 拒绝；操作后状态就地更新，「待审批」计数同步递减。
- outgoing 顶部提供「发起新申请」：设备、范围、**理由必填**；理由为空时内联报错且不提交。提交后新增一条「等待对方审批」，可「撤回申请」。

**命令对应**

| 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 列表 | `list_access_requests(direction)` | `direction` 取 `incoming` / `outgoing` |

### D10 桌面 · 屏幕墙

**界面内容**

- 布局切换：1 / 4 / 9 / 16 路。
- 每格显示设备名、格号与状态标签（在线 / 免确认 / 需审批 / 离线），按预览档 `preview_480p15`（854×480、15fps、≤300 kbps）显示占位。

- 顶部显示解码预算占用（预览格 1 单位、4K60 聚焦格 4 单位，默认 12 单位）与 4K60 并发（≤1）。

**命令对应**

| 用户动作 | 调用命令 | 说明 |
|---|---|---|
| 切换布局 | `start_wall(layout)` / `set_wall_layout(wall_id, layout)` | 返回 `cells`、`degraded`、`degrade_steps` |
| 点选某格 | `focus_wall_cell(wall_id, cell)` | 同一时刻只允许一格聚焦；返回 `session_id` 与 `quality_profile` |

**降级顺序（界面必须展示）**

1. 减格：16 路超过 12 单位预算时先减到 12 格。
2. 预览降档：仍不足时降到 `preview_360p10`。
3. 暂停未聚焦格：预算仍不足时按格号从大到小暂停，保留末帧。

> 原型中的画面为静态占位，预算与降级为真实计算；原型不构成画质通道验收。

## 4. 关键交互

### 4.1 桌面连接状态流

```
主界面 --start_connection--> 连接中 --get_connection_progress(done)--> 会话窗口
                                  |--failed / cancel--> 失败 / 主界面
                                  `--ACCESS_CODE_INVALID / SESSION_BUSY--> 被拒
```

- 连接中只轮询进度，不伪造阶段；原型 0→4 的动画是演示，真实 `completed` 以命令为准。
- 取消使用同一 `task_id`；已完成或已失败时按契约返回失败文案。
- 失败页与被拒页分别是契约错误的不同呈现，不把错误码固定写进界面逻辑。
- 原型点击「连接」会自动演示进入会话；左侧「连接中 / 连接失败 / 连接被拒」可静态查看三种状态。

### 4.2 画质、降级与通路

- 直连档：`4K60`、`1440p60`、`1080p60`、`1080p30`（地板）、`auto`。
- 降档：帧率、p95、丢包、GPU、CPU、带宽连续 3 秒超限即降一档，一次只降一档。
- 回升：连续 10 秒满足条件，一次只升一档，带宽留 30% 余量。
- 上限：每会话自动切换最多 6 次，同一档位最多进入 2 次；达上限锁定当前档，只接受人工指定。
- `auto` 起步 1080p60；4K60 只在 P2P 且带宽探针达标时尝试，不允许「先开 4K 再看」。
- 中继固定 L0–L3，不套用直连档位表；中继任何时刻不得承载 4K60，界面显示「中继模式已降级」。
- `quality_events` 只保留最近 32 条，通过 `get_session_metrics` 读取；界面不丢弃、不改写切换记录。

### 4.3 错误呈现

- `CommandResult.message` 永远原样展示，界面不拼接、不重写。
- `error_code` 只在需要分支时展示/使用：`DEVICE_NOT_FOUND`、`ACCESS_CODE_INVALID`、`SESSION_BUSY`、`TASK_NOT_FOUND`、`SESSION_NOT_FOUND`、`PROFILE_UNSUPPORTED`、`PERMISSION_DENIED`、`HOSTING_ALREADY_ACTIVE`、`HOSTING_NOT_ACTIVE`、`POLICY_INVALID`、`RELAY_UNREACHABLE`。
- 原型只演示 `DEVICE_NOT_FOUND` 与 `ACCESS_CODE_INVALID` 两种状态页；其余错误复用同样的「标题 + message + error_code + 操作」结构。

### 4.4 桌面窗口与视图

- Windows：右侧最小化 / 最大化 / 关闭控件；macOS：左侧交通灯；Linux：平直标题栏。三者仅装饰不同。
- 全屏：会话窗口铺满浏览器视口并隐藏侧栏；按 Esc 或「退出全屏」恢复。
- 工具栏：可收起为「显示工具栏」胶囊，避免遮挡远端画面。
- 指标面板：只读，悬浮于画面右上；不拦截鼠标/键盘输入（真实实现需注意）。

### 4.5 安卓横竖屏

- 竖屏：画面 + 信息卡 + 操作区，适合单手操作。
- 横屏：全屏画面 + 悬浮手势条；手势条固定保留，进入沉浸模式也不消失。
- 键盘与画质使用底部抽屉，一次只开一个；点击外部或关闭按钮收起。
- 权限引导只说明系统权限，不模拟系统弹窗。

### 4.6 账号、免确认、申请制与屏幕墙流转

```
连接页 --账号与设备--> 设备列表 --未登录--> 账号登录 --login_account--> 设备列表
   |                        |--免确认开启--> 会话（免连接码、免逐次确认）
   |                        |--免确认关闭--> 申请与审批 --> 等待被控端审批
   |                        `--被授权--> 会话（按授权范围）
   |--直接输码连接--> 连接中 --> 会话
屏幕墙 --start_wall--> 1/4/9/16 预览格 --focus_wall_cell--> 聚焦格（4K60 并发恒 ≤1）
   |--预算超限--> 减格 --> 预览降 360p10 --> 暂停未聚焦格（逐级，界面显示降级条）
   `--close_wall--> 主界面
```

判定顺序（与契约 v1.3 一致，界面不自行调整）：既有会话 → 同账号且免确认 → 生效授权 → 申请制 → 拒绝。

界面对应的可点闭环：

- 桌面：主界面「连接」→ 连接中 → 会话窗口；会话工具栏「结束会话」→ 主界面；侧栏 7 个入口全部可点。
- 桌面：登录 →（成功）设备列表 → 连接 → 会话；设备列表「待审批」→ 申请与审批 → 批准 / 拒绝后状态就地更新。
- 安卓：连接页 → 连接中 → 会话竖屏 → 横屏 → 返回竖屏 → 断开 → 连接页；连接页「账号与设备」→ 设备列表 → 连接 / 申请审批。
- 屏幕墙：切布局、点格升级、关闭屏幕墙均可点；安卓设备列表中的「屏幕墙」明确置灰不可点。

### 4.7 剪贴板 / 拖拽 / 文件传输

- 全部为原型演示：不读取系统剪贴板、不读写真实文件、不发起网络请求；进度、速率与剩余时间由内联 JS 每 400ms 模拟推进。
- 传输走**低优先级通道**，限速 8 Mbps，不抢占画面码率，也不参与画质档位决策。
- 拖拽：`dragenter` / `dragover` / `dragleave` / `drop` 均 `preventDefault`；进入时整块高亮并提示「松开以传输到远端」，离开恢复。未连接时拖拽只提示「请先建立会话」，不创建传输任务。
- 状态机：`idle → running ↔ paused → done`，可 `running/paused → canceled`，可 `running/paused → failed → running`（失败重试）。取消后暂停 / 继续置灰；失败时仅「失败重试」可用。
- 剪贴板：文本上限 **256 KiB**，超出截断并提示「已截断」；图片上限 **4 MiB**，超出拒绝并提示「已拒绝」。关闭开关后同步按钮置灰，状态显示「同步已关闭」。
- 传输面板在未连接时整体置灰并提示「请先建立会话」；桌面端在侧栏，安卓竖屏在信息卡下方，安卓横屏折叠为「传输」底部抽屉。
- 面板中的「模拟中断」仅用于演示失败重试，不对应契约命令。

## 6. 契约缺口与处理原则

| 项 | 现状 | 本稿处理 |
|---|---|---|
| `start_session` | 契约无此命令 | 连接任务完成后直接进入会话；不臆造命令 |
| 设置页默认画质写入 | 契约无配置写入命令 | 仅呈现偏好；会话内用 `apply_quality_profile` |
| 硬件编码开关 | 契约无对应命令 | 仅呈现，不写「已接入」 |
| 安全开关、固定口令 | 契约无对应命令 | 仅呈现，不写「已接入」 |
| 安卓系统权限 | 契约无对应命令 | 说明系统流程与入口，不写命令 |
| 「被拒」状态 | 无独立错误码 | 复用 `ACCESS_CODE_INVALID` / `SESSION_BUSY` 的 `message` 与 `error_code` 呈现 |
| 中继档位 | 只有 L0–L3 | 按设计书固定值与预算说明呈现，不写死协议常量 |

## 7. 视觉与可访问性

- 深色为默认，浅色为可切换主题；两套 token 使用同一套语义变量（背景、面板、文本、边框、强调、状态色）。
- 字体使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`；ID 与指标使用系统等宽字体栈。
- 不生成图片资源；远端画面、窗口、图标（内联 SVG symbol）、键盘与图表均由 CSS / SVG 绘制。
- 状态色只用于状态：绿=稳定/已连接，琥珀=降级/待授权，红=失败；强调色用于主操作与选中态。
- 所有交互控件使用 `button` / `input` / `select`，关键图标按钮带 `aria-label`；开关使用 `role="switch"` 与 `aria-checked`。

## 9. 设计令牌与两端映射

两端（安卓、桌面）的颜色、字号、间距、圆角、描边、阴影、图标尺寸、控件高度、导航高度与安全区，统一以 [`design-tokens.json`](design-tokens.json) 与 [`设计令牌.md`](设计令牌.md) 为唯一取值来源；原型里的 `:root` / `body.light` 变量必须与令牌逐项一致，不允许各端再各写一套。

**安卓映射到资源值**：`colors.shared.dark` → `res/values/colors.xml`（`rdc_` 前缀，如 `rdc_bg`），`colors.shared.light` → `res/values/colors_light.xml`；字号 → `res/values/dimens.xml` 的 `sp` 项；间距、圆角、控件高度、图标尺寸 → `dimens.xml` 的 `dp` 项；状态栏 `30dp`（横屏 `22dp`）与底部安全区 `16dp` 只是原型预览值，运行时必须用 `WindowInsetsCompat` 读取系统实际值。

**桌面映射到 theme.py**：`colors.shared.dark/light` 一一写入 `src/rdc/ui/theme.py` 的 `DARK` / `LIGHT`（如 `panel2 → panel_2`、`accentHover → accent_2`）；`colors.desktopExtended` 对应 `accent_soft_2`、`accent_border`、`hero_from` 等派生键；字号、圆角、控件高度与 `navigation.desktopSidebarWidth` 落到 QSS 与 `components.py`，侧栏宽度以令牌的 `216px` 为准。

维护规则：修改设计先改 JSON，再在同一提交内同步 `theme.py` 与安卓资源；令牌与原型不一致时以原型为准修正令牌或原型，并在 `设计令牌.md` 第 8 节记录改的是哪边、为什么。
