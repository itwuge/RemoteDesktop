| 项 | 内容 |
|---|---|
| 产物 | `docs/design/ui-v1/登录后界面-v2.html`（单文件、自包含、可点击原型） |
| 说明文档 | `docs/design/ui-v1/登录后界面说明.md`（本文件） |

| 适用版本 | desktop-v1 v1.3 缺口登记（契约-202611-018）之后的登录后界面设计 |
| 阶段 | 原型与说明，不代表功能已实现；本轮未改 `src` 下任何 Python 代码 |

> **边界声明**
>
> 界面只做三件事：**收集参数、调用命令、呈现结果**。不发起网络、不解协议、不做设备发现与准入判定、不做画质决策与降级、不生成或改写错误码与 `message`、不吊销令牌、不写审计、不缓存凭据。
>
> 本文与原型中的设备、账号、消息均为演示数据；真实实现时，所有文案与状态必须来自命令返回值，界面不得自行编造成功或失败。

## 1. 打开方式与深链

双击 `登录后界面-v2.html` 即可打开，无 CDN、无外部字体、无图片请求、无网络请求。

原型顶部工具条提供两个演示开关：**深色/浅色**、**切换未登录态**。后者仅用于演示两态，真实客户端不得提供该开关，登录态只由 `get_account_state()` 决定。

可直接用地址栏复现任意状态：

```
#page=devices&devicesState=loading&theme=light&auth=out&devFilter=online
```

| 参数 | 取值 |
|---|---|
| `page` | `home` / `devices` / `trust` / `messages` / `account` |
| `theme` | `light`（缺省深色） |
| `auth` | `out`（缺省已登录） |
| `devicesState` / `trustState` / `messagesState` | `normal` / `loading` / `empty` / `failed` |
| `devFilter` | `all` / `online` / `offline` |
| `msgFilter` | `all` / `approval` / `binding` / `session` / `grant` / `account` |

## 4. 界面元素与命令对应表

**约定**：表中「来源命令」均为 `src/rdc/commands/` 中已存在的函数；未列出的字段一律不展示。`root` 表示数据接线层注入的页面根数据（由 `get_account_state()`、`list_devices()`、`list_messages()` 汇总），界面只读。

### 4.1 首页

| 界面元素 | 交互 | 命令函数 / 数据来源 | 使用字段 | 说明 |
|---|---|---|---|---|
| 标题问候与副标题 | 只读 | `get_account_state()` + `list_devices()` + `list_messages()` | `account_name`；在线/总数；`unread` | 文案由数据拼接，不写死 |
| 统计卡「在线设备 / 受信设备 / 已绑定设备 / 未读消息」 | 只读 | `list_devices()`、`list_messages()` | `items[].online`、`items[].trusted`；`unread` | 受信 = `trusted=true` 的条目数 |
| 「刷新」按钮 | 点击 | 重新调用 `get_account_state()`、`list_devices()`、`list_messages()` | — | 界面不清空旧数据，等待结果替换 |
| 「快捷连接」按钮 | 点击 | `start_connection(device_id, access_code)`；受信免码见 G5 | `device_id` | 优先取「在线且受信且非本机」的第一台 |

| 最近设备「受信设备 / 需连接码」 | 只读 | `list_devices()` | `trusted` | 受信显示「一键连接」，非受信显示「连接」 |
| 最近设备「在线 / 离线」 | 只读 | `list_devices()` | `online`、`presence_state` | `unknown` 按离线呈现并标注「状态未知」 |

| 账号概览「消息中心 / 账号详情」瓷贴 | 点击 | 仅切换页面 | — | 视图状态，不产生命令 |

## 5. 状态规则

| 状态 | 判定来源 | 呈现 |
|---|---|---|
| 未登录 | `get_account_state().logged_in == false` | 各功能页显示对应「去登录」引导；账号页显示登录/注册表单 |
| 加载中 | 命令未返回（界面自管请求态） | 骨架屏 + 「正在读取…」；禁止先渲染空状态 |
| 空 | `ok=true` 且 `items` 为空 | 说明「为什么空」与「下一步怎么做」 |
| 失败 | `ok=false` | 展示命令 `message`；提供重试；不推断原因 |
| 连接中 | `get_connection_progress().status` 为 `pending`/`running` | 进度条与阶段文案；`cancelable=true` 才可取消 |
| 已连接 | `list_sessions()` 非空或 `get_session_status()` 返回会话 | 显示对端、传输、画质；「结束会话」调 `stop_session()` |
| 未连接 | `list_sessions()` 为空 | 明确「当前没有进行中的会话」+ 快捷连接入口 |

三态切换按钮（`原型状态`）仅存在于原型，用于评审截图；真实界面不得暴露。

## 10. 全中文文案规范（2026-11-10 增补）

### 10.1 规则

1. 产品界面内不出现英文单词：按钮、标签、页签、状态栏、空状态、加载态、提示条、对话框、右键菜单、工具提示（`title`/`setToolTip`）一律中文。
2. 命令名、接口路径、字段名、错误码只允许出现在原型顶部的虚线标注区（`.cmd-tag`、`cmd-note`）与日志详情中，不进入产品文案。
3. 错误只显示中文原因；错误码保留在日志里，由日志页展示。
4. 「设备 ID」统一改为「**设备编号**」；「连接码」保持不变。「设备码」是登录态之外的临时连接凭据，与连接码并列但不混用。

### 10.2 技术标识处理

| 类型 | 写法 | 示例 | 说明 |
|---|---|---|---|
| 分辨率 | 数字 + `p` 或 `×` | `1080p`、`1920×1080` | 保留数字与短符号 |
| 帧率 | 数字 + 「帧/秒」 | `60 帧/秒` | 不写 fps |
| 码率 | 数字 + 单位符号 | `8.0 Mbps` | 单位符号允许 |
| 协议 / 封装版本 | 「协议 v3」「封装 v2」 | `协议 v3` | 版本号保留，单词不出现 |
| 地址与端口 | `IP:端口` | `10.0.0.12:52001` | 原样显示，可复制 |
| 设备编号 | 20 位大写字母数字 | `AAAABBBBCCCCDDDDEEEE` | 等宽字体，可复制 |

### 10.3 平台名判定

**判定：保留产品名原文，加中文描述词，不翻译商标。**

- 显示为「Windows 电脑」「macOS 电脑」「Linux 电脑」「安卓手机」「iPhone」。
- 理由：Windows、macOS、Linux 是微软/苹果/Linux 基金会的产品名与商标，翻译成「视窗」会造成识别困难；「安卓」已是 Android 的通用中文名，但与「安卓手机」连用时语义更完整。
- 登记：这些英文只作为**产品名**出现，不是界面文案；说明文档在此登记，审计时按产品名豁免。
- 未知平台显示「平台未知」，不回退英文原值。
