## 2. 本轮做了什么

### 2.1 统一图标体系

- 新增 `src/rdc/ui/assets/icons/`：55 个线性 SVG（Lucide，ISC），统一 24 网格、`stroke-width=2`、圆头圆角。
- 新增 `src/rdc/ui/icons.py`：加载 SVG、按主题色重着色并缓存；导航项使用 Normal/Active × On/Off 双状态，选中自动变强调色；`refresh_icons()` 在深浅色切换后批量刷新。
- 尺寸统一：导航 18px、正文按钮 15px、状态与提示 16–17px，不再出现混用尺寸的图标。

### 2.2 空状态与配图

- 新增 `src/rdc/ui/components.py`，全部插画由 `QPainter` 自绘，跟随主题取色，无外部图片：
  - `Illustration("devices" | "wall" | "inbox" | "session" | "shield" | "search")`
  - `EmptyState`：插画 + 标题 + 说明 + 可选主按钮
- 覆盖位置：最近会话、设备列表、屏幕墙、申请审批、会话未连接、搜索无结果。

### 2.3 设备卡片

- `DeviceThumbnail`：16:9 渐变占位图 + 网格 + 显示器符号 + 「无实时画面 · 占位缩略图」说明。
- `DeviceCard`：缩略图、设备名称、在线/离线 chip、设备码、系统 chip（`os` / `platform` / `os_name`，缺失时显示「系统未上报」）、所有者 / 被授权、免确认 / 需审批、绑定时间。
- 设备页顶部改为统计卡（已绑定 / 在线 / 需审批），下方为三列卡片网格与空状态切换。

### 2.4 连接页与登录页

- 首页：本机信息改为渐变主视觉卡，一次性口令与启动/停止/刷新独立成组；连接表单与最近会话分区清晰。
- 登录页：左侧品牌区（SECURE ACCESS、主张标题、盾牌插画、三条安全要点），右侧登录/注册标签页与设备令牌说明卡；令牌仍只显示掩码。

### 2.5 配色与层次

- 新增 `src/rdc/ui/theme.py` 双色板与统一 token：背景、卡片、边框、强调、成功、警告、危险、软色。
- 深色为默认，左下角「切换浅色 / 切换深色」即时切换并刷新图标。
- 统一圆角（卡片 14px、控件 8–10px、chip 999px）、间距（8/10/12/16/24）与字号阶梯。
- 软色与半透明边框统一使用 `rgba()`，规避 Qt 把 `#RRGGBBAA` 解析为 `#AARRGGBB` 的问题。

### 2.6 长页面滚动

- `PageBase` 支持 `scrollable`；会话窗、设置、申请审批在 840 高度下不再压缩重叠，改为可滚动内容区。

## 5. 第二轮：可读性、分页与矮窗口加固

### 5.1 浅色次要文字对比度

浅色色板中两档次要文字整体加深，保证 11–12px 小字在卡片和页面底色上可读：

| token | 原值 | 现值 | 说明 |
|---|---|---|---|
| `muted` | `#5c6c81` | `#4a5b70` | 说明文字、设备码、页头副标题 |
| `faint` | `#8b97a7` | `#5f6d7e` | 页脚、提示、滚动条等最次要信息 |

深色色板未改动。

### 5.2 设备卡片分页

- 设备页按每页 9 台（3×3）分页，超过 9 台时显示「第 x / y 页 · 共 N 台」与上一页 / 下一页。
- 仅在界面层对已返回的 `items` 做切分，不新增命令、不改刷新链路；切换分页保留选中态。
- 翻页时先解除旧卡片父子关系再 `deleteLater`，避免重绘瞬间出现新旧卡片叠加。

### 5.3 矮窗口与长页面

- 首页、设备页也改为整页滚动；会话页工具栏拆成两行（导航 / 档位 与 状态 / 操作），避免 1080 宽度下按钮被裁切。
- 本机设备码在页面宽度小于 1000px 时自动降到 24px 字号，1080×720 下完整显示。
- 在 1080×720（窗口允许的最小尺寸）逐页复测：首页、设备、屏幕墙、会话、设置、登录、审批均无重叠、无横向裁切，超出内容由纵向滚动承载。

### 5.4 启动入口实测

- 直接通过项目根的无控制台入口重新拉起应用（当时为 `启动桌面端.bat`，现统一收敛为 `启动桌面端.vbs`），新进程标题 `RDC 远程桌面 · V1`，stderr 为空。
- 用 Windows UI Automation 在真实窗口逐个点击七个导航项并截图，页面与截图一致。
- 点击「切换浅色 / 切换深色」后，导航、按钮、状态图标全部按新主题重绘（脚本校验 36 个带图标按钮，21 个颜色随主题变化，其余为两种主题下同色的白色图标；无空图标）。

## 6. 第三轮：成品感收敛

目标从「补元素」转为「成品感」：统一节奏、收敛状态、压低装饰噪音。代码范围仅 `theme.py`、`components.py`、`icons.py` 与页面 `home / devices / wall / session / account / approvals`；`settings.py` 与主窗口更新入口未改动。

### 6.1 字号阶梯与纵向节奏

| 角色 | 原字号 | 现字号 | 用途 |
|---|---|---|---|
| `#pageTitle` | 26 | 24 | 页面标题 |
| `#sectionTitle` | 15 | 14 | 卡片 / 分组标题 |
| `#cardTitle` | 14 | 13 | 卡片内条目标题 |
| `#metricValue` | 20 | 22 | 设备页统计数值 |
| `#emptyTitle` | 15 | 16 | 空状态主标题 |
| `#chip` | 10 | 11 | 状态胶囊 |

- 页面正文区统一 `spacing=12`，页头与正文之间 12px、卡片内边距 16–20px，六个页面共用同一套节奏。
- `#chip` 圆角 10→9、内边距 `3px 9px`，避免胶囊在 11px 字号下显得松散。

### 6.2 按钮状态收敛

- `QPushButton:pressed` 统一为 `accent_soft` 底 + `accent_border` 边，不再只靠加深底色。
- 补齐 ghost / seg / link 三种变体的 hover、pressed、disabled，禁用态统一 `faint` 前景 + 透明底。
- 图标与文字同基线：按钮图标统一 15px，经 `icons.apply_icon` 走同一条 `QIcon` 通路。

### 6.3 卡片质感与缩略图

- `DeviceCard` 加 `QGraphicsDropShadowEffect`（blur 18 / offset 4 / alpha 30），描边仍走 `line` token，圆角与内边距不变，卡片浮起但不抢焦点。
- `DeviceThumbnail` 重绘去掉「脏」的观感：渐变底 + 右上角强调光（在线 alpha 36 / 离线 16）、网格 alpha 18 / 步长 28、中央圆角占位牌（`accent` alpha 14 填充 + 1px `line_strong` 描边 + monitor 图标）、底部「无实时画面 · 占位缩略图」8.6pt，在线时右上角加 `ok` 色点。

### 6.4 空状态插画

- 光晕 alpha 42→30，面板描边 1.6→1.5，屏幕描边 1.2→1.1，地面阴影 alpha 40/36→26/22；线条与配色在深浅两套下都取自当前主题 token，不再有悬浮感。

### 6.5 微动效

- 页面切换：`fade_in`（170ms，`OutCubic`）对页面整体做一次淡入，结束后移除 `QGraphicsOpacityEffect`，避免影响后续绘制；另有 `QTimer` 兜底清理，保证截图 / 低刷新环境下不会停在 opacity 0。
- 主题切换：`refresh_icons` 末尾对窗口 central widget 做 150ms 淡入，图标与配色一起过渡。
- 未引入位移、缩放、循环动画。

### 6.6 本轮修复

- 会话页「限速」一行右侧说明文字在 1280 宽下被压成两行并与输入框重叠，改为独立一行说明。
- 登录页右侧卡片中段留白过大：标签页改为按内容高度排版（`QSizePolicy.Maximum`），设备令牌卡紧随其后，与其它页面同一套 12/16px 节奏。
- 标签页下划线过重：选中态去掉 `accent_soft` 底色块，改为 2px `accent_border` 下划线 + `accent` 文字，高度不抢视线。

## 7. 已知限制与后续

- 屏幕墙与设备缩略图为占位图形，接入真实帧后可直接替换绘制源，不影响布局。
- 设备列表空状态为插画，卡片态需后端返回 `list_devices` 才有数据。
- 浅色主题次要文字已加深；极端小字号（11px 以下）项目内未使用。
- 设备分页为界面层切分，若后续设备数量很大（数百台以上）再考虑服务端分页或虚拟滚动。
