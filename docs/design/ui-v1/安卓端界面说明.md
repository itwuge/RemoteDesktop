# 安卓端控制端界面 v1 · 说明

- 原型：`docs/design/ui-v1/安卓端界面-v1.html`（单文件、自包含，`file://` 直接打开）
- 说明：`docs/design/ui-v1/安卓端界面说明.md`（本文件）
- 证据：`D:\RDC-Build\evidence\ui\20261110-204233\`（30 张截图 + `interaction-checks.json`）
- 对照基线：桌面端 `docs/design/ui-v1/登录后界面-v2.html` 与 `登录后界面说明.md`
- 本轮边界：只产出原型与说明，未修改 `android/`、`src/`、契约正文与中继配置

原型顶部工具条可切换：主题（深/浅）、登录态（已登录/未登录）、重置演示。手机画布固定 390×844（竖屏）；应用外壳固定竖屏，不随手机旋转。支持以下深链直接复现指定状态：

```
安卓端界面-v1.html#tab=devices&theme=light&orient=landscape&auth=out&state=failed&session=reconnecting
```

- `tab`：`connect` / `devices` / `messages` / `account`（`account` 即底部「我的」）
- `state`：`normal` / `loading` / `empty` / `failed`，作用于当前 tab 对应页面
- `session`：`connected` / `reconnecting` / `failed`
- 其余：`theme=light`、`orient=landscape`、`auth=out`

## 1. 边界与职责

1. **只做控制端**：原型不出现「被控端」「屏幕墙」「投屏墙」等入口；连接页首屏与设置弹层均明确「安卓端只做控制端，不提供被控端与屏幕墙入口」。桌面端的墙功能不进入本原型。
2. **界面不承载业务逻辑**：界面只做三件事——收集参数、调用命令/接口、呈现结果。校验仅限输入格式（20 位设备码、6 位数字连接码、账号/口令非空），不做准入判定、不写令牌、不拼审计。
3. **不新增命令与字段**：所有命令、接口与字段均取自 `docs/contracts/desktop-v1.md` 第三节、契约变更记录 `202611-018`（含第六部分 `/v1` 接口与 6.2 设备字段、6.2.1 审计 detail 键名），缺口统一记录在第 8 节。
4. **演示数据声明**：原型内的账号 `wuge@example.com`、5 台设备、10 条消息、连接码 `318204` 均为演示数据，不代表真机状态；页面底部「数据来源」区块标注了对应命令。
5. **自包含**：无 CDN、无外部字体、无图片请求；图标为内联 Lucide 路径（ISC），占位画面为自绘 SVG/渐变。

## 4. 页面结构与三态

### 4.1 页面清单

| 页面 | scope | 主要区块 | 空状态文案 | 失败文案 |
|---|---|---|---|---|
| 连接 | `connect` | 控制端声明、受信设备（一键连接/刷新）、连接码连接、最近连接、连接进度 | 暂无可一键连接的受信设备；连接码卡片保持可用 | 按第 5 节原因显示，附「重试」与「去登录」 |
| 设备 | `devices` | 绑定入口、筛选（全部/在线/受信）、搜索、按在线/离线分组 | 还没有同账号设备，绑定后可一键连接 | 按原因显示，附「重试」「检查登录状态」 |
| 消息 | `messages` | 全部已读、未读统计、分类筛选（全部/会话/绑定/审批/授权/账号）、按天时间线 | 暂无消息，新会话与审计事件会出现在这里 | 按原因显示，附「重试」「检查登录状态」 |
| 我的 | `mine` | 已登录资料卡、统计三格、入口列表、登录状态、退出登录；未登录登录/注册表单 | 未登录时展示登录/注册入口 | 按原因显示，附「重新登录」 |
| 会话 | 覆盖层 | 标题栏（对端、状态、画质）、画面区、遮罩（连接中/画面恢复中/中断）、控制条 | 无（会话必须有对端） | 恢复中与中断两套遮罩，含中文原因与重试/退出 |

### 4.2 三态机制

- 每个页面有四个同级视图：`data-state-view="normal|loading|empty|failed"`，均带 `data-state-scope`。
- 切换函数 `setPageState(scope, value)` 只切换视图，不发起请求；这类切换仅用于原型演示与验收。
- 加载态使用骨架条（`line` / `line-strong`），深色下仍可辨识；空态与失败态均为独立卡片，不与正常内容混排。
- 未登录时，连接页的受信设备与最近连接、设备页、消息页、我的页分别由 `data-auth-gate` 显示登录引导；用户主动切换「加载中/失败」仍可预览对应视图（原型验收用）。

### 4.3 失败原因与错误码映射

| 界面中文原因（固定四条） | 触发场景 | 命令层错误码 / 原因 |
|---|---|---|
| 网络不通，请检查手机网络后重试。 | 无法访问账号端点、信令或中继；请求超时 | `SIGNALING_UNREACHABLE`、`RELAY_UNREACHABLE`、`DIRECT_FAILED`、`TRANSPORT_CLOSED`、`SESSION_CHANNEL_TIMEOUT` |
| 认证失败，登录态可能已过期，请重新登录。 | 口令错误、令牌过期/吊销、设备归属其他账号 | `AUTH_FAILED`、`CREDENTIAL_INVALID`、`TOKEN_EXPIRED`、`TOKEN_REVOKED`、`TOKEN_INVALID`、`DEVICE_BOUND_OTHER` |
| 被控端未启动，请确认对端已打开 RDC 并处于可连接状态。 | 对端离线、未开启会话服务、中继无可用通道 | `PEER_OFFLINE`、`RELAY_UNAVAILABLE`、连接策略 `relay_unavailable` |
| 设备编号或连接码错误，请核对后重试。 | 设备码不存在、连接码不是 6 位或已失效 | `DEVICE_NOT_FOUND`、`ACCESS_CODE_INVALID` |

错误码常量位于 `src/rdc/core/errors.py`；连接策略原因位于 `src/rdc/connect/policy.py`。界面只消费命令层返回的 `message` 与 `error_code`，不在页面内做错误分类拼接。

## 5. 控件 → 命令 / 接口 / 字段对应表

说明：

- 桌面端与安卓端字段同源。账号、设备、受信、审计类数据在安卓侧由 `RemoteAccountClient` 走 `/v1` HTTP 接口取得，桌面侧对应同名命令函数；会话、画质、输入由 `ControlContract` 转发命令层。
- 「界面职责」一列写明该控件只做参数收集/调用/呈现，不承担判定与副作用。

### 5.1 连接页

| 控件 | 交互 | 命令 / 接口 | 关键字段 | 界面职责 |
|---|---|---|---|---|
| 控制端声明卡 | 展示 | 无（静态文案） | — | 声明只做控制端，不提供被控端/屏幕墙 |
| 受信设备列表 | 加载/刷新 | `list_devices()`；安卓 `RdcAccountService.devices(context)` → `GET /v1/devices` | `items[].device_id`、`display_name`、`online`、`presence_state`、`trusted`、`last_connected_at`、`platform`、`current` | 只筛选 `trusted=true` 并按 `last_connected_at` 倒序呈现 |
| 受信设备行副标题 | 展示 | 同上 | `device_id` 前 4/后 4 位、`last_connected_at` | 相对时间由界面格式化，不猜平台 |
| 「连接」/「一键连接」 | 点击 | `start_connection(device_id, access_code)`；受信免码由 `/v1/access/resolve` 判定 | 入参 `device_id`、`access_code`；出参 `task_id`、`total` | 未受信设备先弹连接码弹层；受信设备直接发起，免码与否由命令层决定 |
| 「刷新」 | 点击 | `list_devices()` | 同上 | 重新拉取列表，失败进失败态 |
| 设备码输入 | 输入 | 无（本地参数） | 20 位，字符集 `[A-Z2-7]`（`DEVICE_ID_PATTERN`） | 仅做长度与字符校验提示 |
| 连接码输入 | 输入 | 无（本地参数） | 6 位数字（`ACCESS_CODE_PATTERN`） | 仅做格式校验提示 |
| 「连接」按钮 | 点击 | `start_connection(device_id, access_code)` | 同上 | 参数齐全后调用；不自行判断设备是否存在 |
| 表单错误行 | 展示 | 无 | 固定中文：请输入设备码与连接码 / 设备码应为 20 位 / 连接码应为 6 位数字 | 输入级校验 |

| 「取消连接」 | 点击 | `cancel_connection(task_id)` | `task_id`；返回 `status=canceled` | 只提交取消，不本地判定 |
| 进度完成 | 自动 | `get_session_status(session_id)` | `state`、`transport_kind`、`quality_profile`、`started_at` | 成功进入会话层；失败按 `message` 展示 |
| 最近连接列表 | 加载/点击 | `list_sessions()` | `session_id`、`peer_device_id`、`state`、`started_at`、`transport_kind` | 点击后重新走 `start_connection`（需要连接码时弹层） |
| 未登录引导 | 展示/跳转 | 无（`get_account_state().logged_in` 判定） | `logged_in` | 引导到「我的」登录 |

## 6. 固定竖屏、滚动与导航状态

1. **tab 切换**：`setTab(next)` 先写 `state.scrolls[current] = #pageScroll.scrollTop`，再隐藏旧页、显示新页，`requestAnimationFrame` 恢复 `state.scrolls[next]`。因此四个 tab 各自保留滚动位置。
2. **固定竖屏**：应用外壳不申请传感器旋转，所有 Activity 锁定竖屏；原型不再提供方向切换。旋转手机时界面不动，会话页不重建、视口倍率与偏移不变。
3. **会话返回**：进入会话时 `state.returnTab = state.tab`；退出（返回、断开、失败退出）都走 `exitSession()` → `setTab(returnTab)`，不会固定回连接页。
4. **全屏与导航**：会话层 `position:absolute; inset:0` 覆盖状态栏以下的整个屏幕；`.in-session` 将底部导航与 home bar 设为 `visibility:hidden`（保留布局占位，避免画面区跳动）。
5. **深链**：`readHash()` 在启动时读取 tab/theme/auth/state/session；交互后 `updateHash()` 用 `history.replaceState` 同步，便于截图和回归复现。

| 编号 | 缺口 | 现状 | 影响 | 建议归属 |

| A1 | 注册时间 | 已解决：`/v1/accounts/me` 与 `get_account_state` 白名单均含 `created_at`（202611-018 增补） | 资料卡可展示，不再记缺口 | 已关闭 |

## 14. 沉浸会话与画面倍率（最终定稿）

### 14.1 规则

1. 进入会话立即进入沉浸模式：隐藏系统状态栏、系统导航栏、应用图标、Logo 与悬浮按钮；静止时画面无任何图标。
2. 操作入口为轻触唤出的浮条：顶部浮条含返回、对端名称、状态、画质、连接信息；底部浮条含键盘、画质、文件、断开，第二行为倍率标签、`还原画面`、`适应屏幕`。3 秒无操作自动淡出，点任一浮条按钮重新计时。
3. 断开确认、失败遮罩、返回提示保留；遮罩打开时不响应画面轻触。
4. **竖屏默认适应屏幕**：`fit = min(W/RW, H/RH)` 等比缩到远端桌面完整可见并居中；远端是横屏就按横屏原始宽高比显示，是竖屏就按竖屏显示，不旋转、不裁切、不拉伸。
5. **倍率范围**：最小为「适应屏幕比例」`fit = min(W/RW, H/RH)`（1080×2400 竖屏视口下 1920×1080 约 0.56×），最大 4.0×。
6. **双指捏合**：向外拉放大、向内捏合缩小，以两指中心为锚点，指下的远端像素保持不动；到 4.0× 或适应屏幕比例即停，不越界。
7. **双指拖动平移**：两指同向移动平移视口，松手停住；平移被钳制在画面内（见 14.2），不露黑边。
8. **双击还原**：300ms 内同位置两次轻触回到默认档（适应屏幕）并居中；单指单击仍为鼠标点击（延迟 240ms 判定，避免误触发）。
9. **远端小于屏幕时**：按 1.0 倍居中显示，四周为屏幕背景色（`--bg`），不放大、不拉伸。
10. 应用外壳固定竖屏：旋转手机不重算倍率，已放大的倍率与偏移原样保留，会话不中断。
11. 不提供双击切换比例、单指拖动平移、拉伸铺满。

### 14.2 触摸坐标换算（必须执行）

设可用区域为 `W×H`（浮条与系统栏不计入），远端画面为 `RW×RH`，当前倍率为 `z`（相对原始像素，1.0 ≤ z ≤ 4.0），画面左上角相对可用区左上角的偏移为 `(panX, panY)`：

```
scale   = z
drawW   = RW * z
drawH   = RH * z
fit     = min(W / RW, H / RH)

// 平移边界钳制（不露黑边）
if (drawW <= W) panX = (W - drawW) / 2
else            panX = clamp(panX, W - drawW, 0)
if (drawH <= H) panY = (H - drawH) / 2
else            panY = clamp(panY, H - drawH, 0)

// 触摸点换算（含单指点击、双指手势起点）
remoteX = clamp(round((touchX - panX) / scale), 0, RW - 1)
remoteY = clamp(round((touchY - panY) / scale), 0, RH - 1)
```

缩放锚点规则（双指中心为锚点，`k` 为新旧倍率之比）：

```
panX' = anchorX - (anchorX - panX) * k
panY' = anchorY - (anchorY - panY) * k
```

边界裁剪规则：

- 触摸落在画面外（钳制前 `remoteX < 0` 或 `> RW-1`）时钳制到最外一列/一行像素，不再平移画面。
- 坐标必须用「原始像素 × 当前倍率 + 当前平移偏移」计算，不能用整块可用区域，也不能用适应屏幕比例。
- 分屏、`还原画面`、`适应屏幕`、双击还原后 `z` 与 `(panX, panY)` 立即失效重算，避免坐标漂移；固定竖屏下旋转手机不触发重算。
- 双指拖动时若指间距变化小于 1.2%，按纯平移处理，避免平移中倍率漂移。
