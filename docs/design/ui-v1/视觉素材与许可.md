## 2. 自绘图形：项目原创

以下图形不依赖任何外部图片文件，全部在项目源码中用 `QPainter` / `QPainterPath` / 渐变实时绘制，版权归本项目所有：

| 组件 | 文件 | 用途 |
|---|---|---|
| `BrandMark` | `src/rdc/ui/components.py` | 侧栏品牌标：渐变圆角方块 + 显示器符号 |
| `StatusDot` | `src/rdc/ui/components.py` | 在线 / 离线 / 警告状态点 |
| `Illustration` | `src/rdc/ui/components.py` | 空状态插画（devices / wall / inbox / session / shield / search） |
| `DeviceThumbnail` | `src/rdc/ui/components.py` | 设备卡片 16:9 占位缩略图 |
| `WallCellButton` | `src/rdc/ui/components.py` | 屏幕墙预览格占位画面 |
| `app_icon` | `src/rdc/ui/icons.py` | 应用窗口图标，由品牌标图形生成 |

这些图形随主题 token 取色，深浅色切换自动适配，不含第三方素材。

## 3. 字体

- 仅使用系统字体栈（Windows 下为 Segoe UI / 微软雅黑回退），未嵌入、未分发任何字体文件，无字体许可义务。
- 字号与字重在 `src/rdc/ui/theme.py` 统一为阶梯，不使用外部字体资源。

---

## 4. 明确未使用的内容

- 未复制 ToDesk、向日葵、RustDesk 等任何上游产品的界面素材、图标包或源码。
- 未抓取任何网站截图、应用截图作为素材。
- 未引入网络图片、CDN 资源、付费图库或生成式图片服务。
- 界面中的设备码、会话、指标均为本机命令返回或显式标注的演示数据，不是素材图片。
- 第三轮「成品感」美化为既有图标的着色、自绘图形参数与 QSS 调整，未新增任何外部素材或图片文件。

---

## 5. 复核方法

1. 图标：核对 `src/rdc/ui/assets/icons/` 下文件名与 Lucide 仓库同名图标一致，`LICENSE-lucide.txt` 为 ISC 原文。
2. 自绘：在 `src/rdc/ui/components.py` 中检索 `paintEvent`，所有插画均由绘图 API 生成，无 `QPixmap("*.png")` 类外部图片加载（应用图标除外，且由自绘图形生成）。
3. 资源引用：`src/rdc/ui/` 下不存在 `.png` / `.jpg` / `.webp` 素材文件。
