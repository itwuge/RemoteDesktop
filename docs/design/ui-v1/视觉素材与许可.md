## 2. 自绘图形：项目原创

以下图形不依赖任何外部图片文件，全部在项目源码中用 `QPainter` / `QPainterPath` / 渐变实时绘制，版权归本项目所有：

| 组件 | 文件 | 用途 |
|---|---|---|
| `BrandMark` | `src/rdc/ui/components.py` | 侧栏品牌标：渐变圆角方块 + 显示器符号 |
| `StatusDot` | `src/rdc/ui/components.py` | 在线 / 离线 / 警告状态点 |
| `Illustration` | `src/rdc/ui/components.py` | 空状态插画（devices / wall / inbox / session / shield / search） |
| `DeviceThumbnail` | `src/rdc/ui/components.py` | 设备卡片 16:9 占位缩略图 |
| `WallCellButton` | `src/rdc/ui/components.py` | 屏幕墙预览格占位画面 |
| `app_icon` | `src/rdc/ui/icons.py` | 应用窗口图标，由品牌标图形生成 |

这些图形随主题 token 取色，深浅色切换自动适配，不含第三方素材。

## 3. 字体

- 仅使用系统字体栈（Windows 下为 Segoe UI / 微软雅黑回退），未嵌入、未分发任何字体文件，无字体许可义务。

## 4. 明确未使用的内容

- 未复制 ToDesk、向日葵、RustDesk 等任何上游产品的界面素材、图标包或源码。
- 未抓取任何网站截图、应用截图作为素材。
- 未引入网络图片、CDN 资源、付费图库或生成式图片服务。
- 界面中的设备码、会话、指标均为本机命令返回或显式标注的演示数据，不是素材图片。
- 第三轮「成品感」美化为既有图标的着色、自绘图形参数与 QSS 调整，未新增任何外部素材或图片文件。

## 5. 应用图标（app-icon）

| 项 | 内容 |
|---|---|
| 名称 | RDC 应用图标（方向 A：显示器 + 双向连接箭头） |
| 来源 | 本项目自绘，`QPainter` 参数化绘制，无外部图片、字体或商标素材 |
| 绘制源 | `src/rdc/ui/icons.py`（`app_pixmap` / `_app_plate` / `_app_mark`） |
| 生成源 | `scripts/make_app_icon.py`（三方向候选、全尺寸 png、ico、icns、平台铺开） |
| 产物目录 | `assets/app-icon/`：`rdc.ico`、`rdc.icns`、`png/rdc-<16..1024>.png`、`preview-*.png` |
| 许可 | 项目原创，版权归本项目所有，随项目分发；不涉及第三方许可义务 |

取色与图形取舍：

| 元素 | 取值 | 说明 |
|---|---|---|
| 底板渐变 | `#6FA8FF` → `#3B7BF6` → `#1F55CC` | 取自主题强调色 `accent` 的浅/中/深三段，深浅桌面下都有边界 |
| 字形 | 白色 `#FFFFFF` | 与 24px 以上笔画保持 5%~6% 边长的线宽，避免细线在 16px 消失 |
| 小尺寸内箭头 | 深蓝 `#1B4099` | 16~24px 退化为实心屏幕，箭头用底色压白，防止糊成一团 |
| 尺寸档位 | 16/22/24/32/48/64/72/96/128/144/192/256/512/1024 | 每档按目标像素重绘，不做位图缩放 |

分发落点：

| 出口 | 载体 |
|---|---|
| 桌面快捷方式 | `RDC 远程桌面.lnk` 的 `IconLocation` → `assets/app-icon/rdc.ico` |
| 脚本入口 | `启动桌面端.vbs` 由快捷方式调用，不单独带图标，沿用快捷方式图标 |
| Windows 可执行文件 | PyInstaller `--icon` 嵌入 `rdc.ico`（便携包与安装版同源） |
| 安装包 | NSIS `MUI_ICON` + 安装目录 `rdc-desktop.ico`，卸载项 `DisplayIcon` |
| Qt 主窗口 / 任务栏 | `icons.app_icon()` 内置 16~256 原尺寸位图，不随主题换色 |
| Linux | `packaging/linux/rdc-desktop.desktop` + `packaging/linux/icons/hicolor/*/apps/rdc-desktop.png` |
| Android | `mipmap-anydpi-v26/ic_launcher.xml` + `drawable/ic_launcher_foreground.xml` + `mipmap-*/ic_launcher.png` |

方向 B（字母 R 几何构成）与方向 C（屏幕 + 光标）仅作为设计候选保留在 `assets/app-icon/preview-*.png`，
未进入构建与分发；两者同样是本项目自绘，不含第三方素材。

## 7. 复核方法

1. 图标：核对 `src/rdc/ui/assets/icons/` 下文件名与 Lucide 仓库同名图标一致，`LICENSE-lucide.txt` 为 ISC 原文。
2. 自绘：在 `src/rdc/ui/components.py` 中检索 `paintEvent`，所有插画均由绘图 API 生成，无 `QPixmap("*.png")` 类外部图片加载（应用图标除外，且由自绘图形生成）。
3. 资源引用：`src/rdc/ui/` 下不存在 `.png` / `.jpg` / `.webp` 素材文件。
