# 屏幕墙设计 v1

| 项 | 内容 |
|---|---|
| 产物 | 桌面端屏幕墙（1/4/9/16 宫格） |
| 契约 | `docs/contracts/desktop-v1.md` v1.5 第 28 至 31、45 至 47 条、3.4 与 3.7 硬约束 |
| 实现 | `src/rdc/wall/budget.py`、`src/rdc/commands/wall.py`、`tests/test_wall_budget.py` |
| 阶段 | 设计与本地原型；真实多路解码未接入 |

## 1. 硬约束

**严禁 N 路 4K60 同时解码。** 任何时刻 4K60 解码路数不得大于 1；屏幕墙不是绕过档位表的通道。预览格不进入直连四档，始终为独立预览档。

## 2. 档位

| 用途 | 档位 | 分辨率@帧率 | 单格码率 | 说明 |
|---|---|---|---|---|
| 预览（默认） | `preview_480p15` | 854×480@15 | ≤300 kbps | 全部格默认；低功耗、低带宽 |
| 预览（降级） | `preview_360p10` | 640×360@10 | ≤180 kbps | 预算仍不足或网络劣化时使用 |
| 聚焦 | `focus` → 直连四档 | 4K60 / 1440p60 / 1080p60 / 1080p30 | 按 3.10 档位表 | 同一时刻只允许 1 格 |

预览档不属于 3.10 的直连档位表，也不参与 `apply_quality_profile` 的 profile 枚举；预览与聚焦的切换由屏幕墙命令完成。

## 3. 解码预算

| 项 | 单位 |
|---|---|
| 预览格 | 1 |
| 4K60 聚焦格 | 4 |
| 默认预算 | 12 |

换算结果（默认预算 12）：

| 布局 | 全预览 | 1 格聚焦（4K60） |
|---|---|---|
| 1 路 | 1 单位，正常 | 4 单位，正常 |
| 4 路 | 4 单位，正常 | 4+3=7 单位，正常 |
| 9 路 | 9 单位，正常 | 4+8=12 单位，正常 |
| 16 路 | 16 > 12，减格到 12 | 4+11=15 > 12，暂停 3 格未聚焦 |

预算为配置项；资源基线变化时只改预算，不改档位表。

## 4. 超限降级顺序

固定三级，每次只做一级，结果写入 `degraded` 与 `degrade_steps`：

1. **减格**：从最高格号开始移除，直到预算够用。
2. **降预览档**：预览从 `preview_480p15` 降到 `preview_360p10`。
3. **暂停未聚焦格**：停止解码，保留最后一帧；聚焦格不受影响。

界面必须显示「已降级」标识与当前生效的降级级别，不得静默降级。

## 5. 交互

- 进入屏幕墙：选择布局 → 全部格以预览档拉流。
- 点选某格：该格升级为聚焦档，其余格保持预览；预算不足时按上述顺序降级。
- 再次点选已聚焦格或按 Esc：退回全预览。
- 关闭屏幕墙：释放全部预览与聚焦资源。

## 6. 本地可跑原型

`src/rdc/commands/wall.py` 提供不依赖网络与解码器的命令层实现，可直接：

```powershell
$env:PYTHONPATH='src'
python -c "from rdc.commands.wall import WallService; s=WallService(); w=s.start_wall(16); print(w.data['degraded'], len(w.data['cells'])); f=s.focus_wall_cell(w.data['wall_id'],0); print(f.data['units_used'], f.data['concurrent_4k60'])"
```

原型口径：

- 预览流**未接真实视频**，以格状态与档位字段模拟；界面原型中的画面为静态占位。
- 预算、降级与 4K60 唯一性为真实计算结果，有单测覆盖。
- 本原型不构成画质通道验收，也不产生任何性能数据。
