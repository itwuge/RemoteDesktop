## 7. 不采纳项与理由

| 功能 | v1 是否有 | v2 原型是否有 | 处理（补回 / 不采纳 + 理由） |
| --- | --- | --- | --- |
| 设备卡「重命名」 | 有入口但置灰（契约无命令） | 有入口但置灰 | **不采纳为可用功能**：不改 `src/rdc/commands`，不能伪造命令；保留置灰提示 |
| 本地累计未读、客户端自行推进已读水位 | 无（服务端为准） | 无 | **不采纳**：`unread` / `read_until` 以服务端返回为准，避免多端不一致 |
| 会话画面拉伸填满容器 | 无（保持原始比例） | 无 | **不采纳**：拉伸会误判远端画面，保持等比与可缩放 |
| 安卓横屏与旋转 | 无（固定竖屏） | 无 | **不采纳**：应用外壳固定竖屏，只让画面按倍率缩放 |
| 屏幕墙 16 路以上、安卓端屏幕墙 | 无 | 无 | **不采纳**：超出当前 `wall` 契约与安卓控制端定位 |
| 令牌明文显示 / 复制 | 无 | 无 | **不采纳**：安全边界，令牌只显示首尾各 4 位 |
| 更新静默强制安装 | 无 | 无 | **不采纳**：下载、校验、安装都需用户确认 |
| 删除设备时卸载对端 | 无 | 无 | **不采纳**：删除只解绑并移出列表，不改变对端安装状态 |
| 剪贴板密码类内容自动同步 | 无 | 无 | **不采纳**：密码类内容需会话内二次确认，图片超 8 MB 只提示手动发送 |
| 安卓端被控端 / 完整文件管理 | 无 | 无 | **不采纳**：安卓仅控制端，文件传输从会话浮条进入 |

## 8. 本次变更：安卓倍率（验收口径）

| 变更项 | v1 口径 | v2 口径 | 处理 |
| --- | --- | --- | --- |
| 默认开局倍率 | 1.0 倍原始像素，画面大于视口时直接裁切 | **适应屏幕**：`fitScale = min(可视宽 ÷ 远端宽, 可视高 ÷ 远端高)`，相对倍率 1.0× 表示适应，不是 1:1 | **本次变更**（原 1.0 倍开局 → 默认适应屏幕） |
| 倍率标签 | 直接显示绝对倍率 | 适应态显示「适应屏幕」，放大后显示相对倍率（最大「4.0×」），侧栏同时给出绝对倍率与占原始像素百分比 | **本次变更** |
| 放大上限 | `MAX_ZOOM = 4`，但默认从 1.0 起算 | `MAX_ZOOM = 4` 为相对适应屏幕的放大倍数；实际 `scale = fitScale × 相对倍率` | **本次变更** |
| 平移边界 | 允许平移到画面外，可能露黑边 | 按可见区域钳制：内容大于视口时取 `[视口-内容, 0]`，小于视口时居中；不露黑边 | **本次变更** |
| 「还原」行为 | 回到 1.0 倍原始像素 | 回到「适应屏幕」（相对 1.0×），并居中 | **本次变更** |
| 「回到左上角」 | 无 | 放大后将平移复位到内容左上角，仍受边界钳制 | **新增** |
| 源画面方向 | 只演示横屏源 | 横屏源保持横向、竖屏源保持竖向，只按宽高比适配，不旋转源画面；原型可切换 1920×1080 / 1080×1920 验证 | **本次补充** |
| 固定竖屏外壳 | 有 | 有，且作为硬要求写入原型与说明 | 保留 |
| 旧「1.0 倍原始像素」文案 | 有 | 已全部删除，改为「默认适应屏幕 / 相对 1.0×」 | **本次变更** |
