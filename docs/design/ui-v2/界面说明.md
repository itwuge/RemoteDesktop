# 界面说明 · ui-v2（现行基准）

**版本约定（先读这一段）**：任何 UI 改版都必须新建 `docs/design/ui-v3/`、`docs/design/ui-v4/` 这样的新目录，旧目录只读保留、不修改、不覆盖；每个版本目录必须自带四件套：原型、说明、令牌、与上一版的功能对照表。`docs/design/ui-v2/` 是当前唯一现行基准，`docs/design/ui-v1/` 中的 `登录后界面-v2.html`、`安卓端界面-v1.html` 与旧令牌均已被本目录取代，只能作为历史参考，不再作为实现或验收依据。

## 1. 本版范围

- 桌面原型：`桌面原型.html`，12 个可切换页面，保留 v1 的首页/设备/信任设备/消息/账号 5 页，补回设置、屏幕墙、会话窗口、文件传输、剪贴板、申请与审批、更新面板 7 页。
- 安卓原型：`安卓原型.html`，完整纳入 v1 最新版内容：固定竖屏外壳、全屏倍率、浮条、浅/深两套主题、连接码连接、最近连接、设备/消息/我的。
- 令牌：`design-tokens.json`（208 条，含 `brandMark`）与 `设计令牌.md`，桌面深/浅与安卓浅/深共用同一套变量。
- 对照：`v1→v2功能对照表.md`，逐项说明补回、保留与不采纳。
- 截图：`screenshots/`，命名规则 `页面-主题.png`。

v1 的功能基线不是某个 HTML，而是当前 PySide6 实现：`src/rdc/ui/pages/*.py` 的 11 个页面加 `update_panel.py` 更新面板。本说明中的命令函数均来自 `src/rdc/commands/`，共 50 个契约命令。

安卓口径：**应用外壳固定竖屏**，不随手机旋转；远程画面按原始比例显示，不拉伸、不裁切；倍率只改变画布缩放与平移，不改变远端分辨率。

### 4.1 安卓画面倍率硬要求（本次验收）

1. **固定竖屏**：应用外壳固定竖屏，不跟随手机旋转；会话层只占据竖屏视口。
2. **默认适应屏幕**：连上后的默认显示是「适应屏幕」，整块远程画面等比缩放到完全可见，四边不裁切、不拉伸。
   `fitScale = min(可视宽 ÷ 远端宽, 可视高 ÷ 远端高)`；`相对倍率 1.0× = 适应屏幕`，不是 1:1 原始像素开局。原型中 `VIEW.zoom = 1` 表示适应，实际 `VIEW.scale = fitScale × VIEW.zoom`。
3. **原始宽高比**：横屏远端（如 1920×1080）显示为横向内容，竖屏远端（如 1080×1920）显示为竖向内容；只按宽高比适配，**不旋转源画面**。原型侧栏可切换「横屏源 / 竖屏源」验证。
4. **放大与平移**：最大放大 4 倍相对倍率（`MAX_ZOOM = 4`）；平移边界按可见区域钳制，画面覆盖视口、不露黑边。「还原」回到「适应屏幕」（相对 1.0×），不是回到 1.0 倍原始像素；另提供「回到左上角」把平移复位到内容左上角。
5. **旧口径清理**：已删除所有「以原始像素 1:1 开局」「还原回到 1.0 倍」的旧表述；适应态标签统一为「适应屏幕」，放大后显示相对倍率（如 4.0×），侧栏同时给出绝对倍率与占原始像素百分比。

## 7. 主题与令牌

- 桌面 `:root` 为深色，`body.light` 覆盖浅色；安卓 `:root` 为深色，`body.light` 覆盖浅色。
- 两端共用 `design-tokens.json` 的 `colors.shared.dark/light`、`typography`、`spacing`、`radius`、`controlHeight`、`navigation`、`brandMark`。
- 远程画面始终使用深色媒体层（`--media-*`），不跟随浅色主题翻转，避免影响画面判读。
- 新增令牌的顺序：先改 `design-tokens.json`，再同步两端，禁止只在一端加常量。

## 8. 自检命令说明

自检使用 Playwright 的 Edge 通道（`channel="msedge"`），不依赖 `scripts/gate.py` 或 pytest。把下面脚本存为临时文件后执行 `python check_ui.py`；脚本只读原型，不写仓库。

```python
from playwright.sync_api import sync_playwright
from pathlib import Path

root = Path("docs/design/ui-v2")
errors, clicks = [], 0
pages = ["home", "devices", "trust", "messages", "account", "settings",
         "wall", "session", "transfer", "clipboard", "approvals", "update"]

with sync_playwright() as p:
    browser = p.chromium.launch(channel="msedge", headless=True)
    page = browser.new_page(viewport={"width": 1440, "height": 980})
    page.on("console", lambda m: errors.append(m.text) if m.type == "error" else None)
    page.on("pageerror", lambda e: errors.append(str(e)))
    page.goto((root / "桌面原型.html").resolve().as_uri())
    for name in pages:
        page.click(f'[data-goto="{name}"]'); clicks += 1
        assert page.eval_on_selector(f'.page[data-page="{name}"]', "e => !!(e.offsetWidth || e.offsetHeight)")
        for state in ["normal", "loading", "empty", "failed"]:
            box = page.query_selector(f'.proto-box[data-proto="{name}"]')
            if box:
                page.click(f'.proto-box[data-proto="{name}"] [data-state-value="{state}"]'); clicks += 1
    for theme in ["light", "dark"]:
        page.click(f'[data-theme-btn="{theme}"]'); clicks += 1
    ap = browser.new_page(viewport={"width": 1280, "height": 1000})
    ap.on("pageerror", lambda e: errors.append(str(e)))
    ap.goto((root / "安卓原型.html").resolve().as_uri())
    for tab in ["connect", "devices", "messages", "account"]:
        ap.click(f'[data-tab="{tab}"]'); clicks += 1
    for theme in ["light", "dark"]:
        ap.click(f'#themeSeg button[data-theme="{theme}"]'); clicks += 1
    browser.close()

print("页面数", len(pages), "点击", clicks, "报错", len(errors))
```

截图命令：同一 Playwright 会话中按 `screenshots/{页面}-{深色|浅色}.png` 命名截图；桌面 12 页各深/浅一套，安卓 4 个主页面各深/浅一套，另加会话全屏、会话浮条、竖屏源、四倍放大各深/浅一套与屏幕墙九路浅色一张。
