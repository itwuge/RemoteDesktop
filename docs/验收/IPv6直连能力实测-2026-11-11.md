## 四、受阻层级定位

```
运营商/光猫 ──(未下发全局前缀)── 路由器 LAN ──(RA 只有 ULA fd9c:eb94:e522::/48)── Windows 本机
                                        └── VMware NAT(VMnet8, 无 IPv6) ── Ubuntu 虚机(未运行)
```

1. **第一层（根因）**：路由器 LAN 侧 IPv6 已启用（有 RA、有 ULA、有 ULA 网关），但**没有全局前缀**，也没有 `::/0`。常见原因：WAN 拨号未开 IPv6 / 运营商未下发 DHCPv6-PD / 光猫桥接但路由器 IPv6 WAN 未配置。
2. **第二层**：即使前缀下发到 LAN，当前虚机在 VMware NAT 后面，拿不到该前缀；需桥接或给 NAT 开 IPv6。
3. 该判断**不能**由主机侧区分「PD 还是 SLAAC」，需看路由器 WAN 状态页是否显示已获取 IPv6 前缀（非本机可读）。
