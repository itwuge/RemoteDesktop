### 3.4 生成 SHA-256 汇总

```powershell
$dir = "D:\RDC-Build\artifacts\desktop"
$out = "D:\RDC-Build\release-sim\v1.0.0\SHA256SUMS.txt"
New-Item -ItemType Directory -Force (Split-Path $out) | Out-Null
Get-ChildItem $dir -File | Where-Object { $_.Name -match '^rdc-desktop-1\.0\.0-' } |
  ForEach-Object { $h = (Get-FileHash -Algorithm SHA256 $_.FullName).Hash.ToLower(); "{0}  {1}" -f $h, $_.Name } |
  Set-Content -Encoding ascii $out
Get-Content $out
```

### 3.5 界面资源核对清单（冻结包必含）

预打包曾出现图标丢失，发布线在出包后、生成 SHA-256 前必须按本表核对。

| 来源路径 | 冻结包内去向 | 用途 | Windows | Linux |
| --- | --- | --- | --- | --- |
| `src/rdc/ui/assets/icons/`（55 个 `.svg` + `LICENSE-lucide.txt`） | `rdc/ui/assets/icons/` | 界面图标与许可 | `--add-data` | `--add-data` |
| `deploy/relay/ca.crt` | `rdc/ui/assets/ca.crt` | 中继 TLS 校验（界面层读取） | `--add-data` | `--add-data` |
| `deploy/relay/ca.crt` | `rdc/assets/ca.crt` | 中继 TLS 校验（运行层读取） | `--add-data` | `--add-data` |
| `assets/app-icon/rdc.ico` | 嵌入 `rdc-desktop.exe` 与安装包 | 可执行文件/安装器图标 | `--icon`、NSIS `ICON_FILE` | 不适用 |
| `packaging/linux/icons/hicolor/<9 个尺寸>/apps/rdc-desktop.png` | `/usr/share/icons/hicolor/<尺寸>/apps/rdc-desktop.png` | 桌面图标 | 不适用 | deb |
| `packaging/linux/rdc-desktop.desktop` | `/usr/share/applications/rdc-desktop.desktop` | 启动项 | 不适用 | deb |
| 构建脚本生成 | 便携包根目录 `portable.marker`、`data/config.json`、`data/update-source/`、`使用说明.txt` | 便携模式与更新源 | 构建脚本 | 构建脚本 |

核对命令（出包后执行）：

```powershell
$root = "D:\RDC-Build\build\desktop"   # 以实际 PyInstaller 输出目录为准
$svg = (Get-ChildItem "$root\rdc\ui\assets\icons" -Filter *.svg -File).Count
$lic = Test-Path "$root\rdc\ui\assets\icons\LICENSE-lucide.txt"
$ca1 = Test-Path "$root\rdc\ui\assets\ca.crt"
$ca2 = Test-Path "$root\rdc\assets\ca.crt"
"svg={0} license={1} ca_ui={2} ca_core={3}" -f $svg, $lic, $ca1, $ca2
if ($svg -ne 55 -or -not $lic -or -not $ca1 -or -not $ca2) { throw "界面资源缺失" }
```

Linux deb 另查：`dpkg-deb -c rdc-desktop-1.0.0-linux-x64.deb` 输出必须包含 9 个尺寸的 `usr/share/icons/hicolor/<尺寸>/apps/rdc-desktop.png` 与 `usr/share/applications/rdc-desktop.desktop`。任一缺失即阻断发布。

## 5. 校验方式

```powershell
Get-FileHash -Algorithm SHA256 <文件绝对路径>
```

```bash
sha256sum <文件绝对路径>
```

- 每个发布物的大小与 SHA-256 必须与本清单第 1 节回填值逐字一致。
- 更新清单中的 `assets[].sha256` 与 `assets[].size` 必须与发布物实际值一致，否则客户端会拒绝下载或安装。
- 更新清单必须带 `signature`（Ed25519），`key_id` 与客户端内置公钥一致。
