## 二、背景与动因

| 项目 | 填写内容 |
|---|---|
| 触发来源 | 用户 2026-11-10 拍板：账号模式、设备绑定与授权列表、申请制审批、同账号免登录、屏幕墙四项全部并入 V1 首版，契约走内部小版本增量 |
| 为什么必须改 | 1. v1.1 只有 13 个会话类命令，没有任何账号、设备归属与授权入口，第二段里程碑无合法调用面；2. 申请制要求「申请 → 审批 → 有时限、可一次性授权」，需要独立命令与可审计状态，不能靠界面约定；3. 设备绑定与授权撤销要求即时生效，必须由命令层给出明确的撤销与失效返回 |
| 备选方案与未采用原因 | 1. 把账号信息塞进 `start_connection` 的可选参数：不采纳，连接与会话命令不承载账号生命周期，签名会被挤出语义；2. 用配置文件维护授权列表：不采纳，撤销无法即时生效，且不可审计；3. 等到「v2」再统一设计：不采纳，用户已定 V1 首版范围，对外不出现 v2。采用 v1.2 加法变更 |
| 判定顺序 | 同一账号免登录与申请制的判定顺序在 v1.3 定义，本记录只落账号、绑定、授权与申请制的数据与命令 |

## 四、新增命令（v1.2）

统一返回 `CommandResult`；长任务阈值 200ms 仍适用，以下命令均为同步短操作。

| 序号 | 命令函数 | 完整签名 | 成功时 data | 错误码 |
|---|---|---|---|---|
| 14 | register_account | `register_account(account: str, password: str) -> CommandResult` | `{"account_id": str, "created_at": str}` | 无专用码，账号已存在只给 `message` |
| 15 | login_account | `login_account(account: str, password: str) -> CommandResult` | `{"account_id": str, "device_token": str, "session_token": str, "expires_at": str}` | `ACCOUNT_NOT_FOUND`、`CREDENTIAL_INVALID` |
| 16 | refresh_session_token | `refresh_session_token(device_token: str) -> CommandResult` | `{"session_token": str, "expires_at": str}` | `TOKEN_EXPIRED`、`TOKEN_REVOKED` |
| 17 | bind_device | `bind_device(device_id: str, access_code: str) -> CommandResult` | `{"device_id": str, "bound_at": str}` | `DEVICE_NOT_FOUND`、`ACCESS_CODE_INVALID` |
| 18 | unbind_device | `unbind_device(device_id: str) -> CommandResult` | `{"device_id": str, "status": str}` | `DEVICE_NOT_FOUND` |
| 19 | list_devices | `list_devices() -> CommandResult` | `{"items": list}` 每项含 `device_id`、`display_name`、`bound_at`、`online`、`require_confirm` | 无 |
| 20 | list_grants | `list_grants(device_id: str) -> CommandResult` | `{"items": list}` 每项含 `grant_id`、`subject`、`scope`、`expires_at`、`transferable`、`revoked_at` | `DEVICE_NOT_FOUND` |
| 21 | revoke_grant | `revoke_grant(grant_id: str) -> CommandResult` | `{"grant_id": str, "status": str}` | `GRANT_INVALID` |
| 22 | request_access | `request_access(device_id: str, scope: str, reason: str) -> CommandResult` | `{"request_id": str, "status": str}` | `DEVICE_NOT_FOUND`、`PERMISSION_DENIED` |
| 23 | approve_access | `approve_access(request_id: str, ttl_seconds: int, one_time: bool) -> CommandResult` | `{"grant_id": str, "expires_at": str, "one_time": bool}` | `REQUEST_NOT_FOUND`、`PERMISSION_DENIED` |
| 24 | reject_access | `reject_access(request_id: str, reason: str) -> CommandResult` | `{"request_id": str, "status": str}` | `REQUEST_NOT_FOUND`、`PERMISSION_DENIED` |
| 25 | list_access_requests | `list_access_requests(direction: str) -> CommandResult` | `{"items": list}`；`direction` 取 `incoming`、`outgoing` | 无专用码，非法 direction 只给 `message` |
| 26 | get_audit_log | `get_audit_log(device_id: str, since: str) -> CommandResult` | `{"items": list}` 每项含 `ts`、`event`、`actor`、`target`、`result`、`detail` | `DEVICE_NOT_FOUND` |

## 五、数据模型补充

| 对象 | 字段 | 约束 |
|---|---|---|
| 账号 | `account_id`、`account`、`password_hash`、`password_salt`、`created_at`、`password_changed_at` | 口令只存 PBKDF2-HMAC-SHA256 派生值与随机盐；明文不落盘、不进日志 |
| 设备 | `device_id`、`owner_account_id`、`display_name`、`bound_at`、`require_confirm` | 一个账号可绑定多台设备；同一台设备可被多个账号持有授权 |
| 设备令牌 | `token_hash`、`device_id`、`issued_at`、`expires_at`、`revoked_at` | 只存 SHA-256 摘要；吊销、解绑、改密必须立即失效 |
| 会话令牌 | `token_hash`、`device_id`、`account_id`、`expires_at`、`revoked_at` | 短时令牌，默认 15 分钟；吊销后在线会话立即踢下线 |
| 授权 | `grant_id`、`device_id`、`subject_account_id`、`scope`、`expires_at`、`transferable`、`one_time`、`used_at`、`revoked_at` | 有效期到期或已用（一次性）即失效；撤销即时生效 |
| 申请 | `request_id`、`device_id`、`requester_account_id`、`scope`、`reason`、`status`、`created_at`、`decided_at`、`decided_by` | `status` 取 pending、approved、rejected、expired；拒绝必须落库并进审计 |
| 审计 | `ts`、`event`、`actor`、`target`、`result`、`detail` | 事件名固定为 `account.register`、`account.login`、`account.password_changed`、`device.bind`、`device.unbind`、`grant.create`、`grant.revoke`、`access.request`、`access.approve`、`access.reject`、`trust_policy.change`、`session.kicked` |

## 六、权限模型（v1.2）

| 操作 | 允许对象 | 判据 |
|---|---|---|
| 绑定设备 | 已登录账号 | 需持有效设备临时连接码；绑定后写入设备所有者 |
| 解绑设备 | 设备所有者 | 解绑即吊销该设备全部设备令牌与会话令牌，并踢掉在线会话 |
| 查看授权列表 | 设备所有者、被授权账号 | 被授权账号只能看到与自己相关的授权 |
| 撤销授权 | 设备所有者、授权发起人 | 撤销即时生效；撤销事件进审计 |
| 发起申请 | 任意已登录账号 | 目标设备存在且未对本人开启免确认 |
| 审批 / 拒绝 | 设备所有者或被控端本机 | 审批必须给出 `ttl_seconds` 与 `one_time`；拒绝可给理由 |
| 改密 | 账号本人 | 改密后该账号名下全部设备令牌与会话令牌立即失效 |
