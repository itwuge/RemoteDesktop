## 1. 新增命令函数

| 函数 | 入参 | 返回 | 说明 |
|---|---|---|---|
| `refresh_update_status()` | 无 | `CommandResult` | 读取配置的更新源与清单，返回是否有新版本、说明、是否强制、最低可运行版本、来源标识 |
| `start_update_download()` | 无 | `CommandResult` | 必须先检查出可用更新；返回 task_id，后台线程下载并做 SHA-256 校验 |
| `get_update_progress(task_id)` | `task_id: str` | `CommandResult` | 轮询进度、已下载字节、校验结果与安装包路径 |
| `cancel_update_download(task_id)` | `task_id: str` | `CommandResult` | 取消下载并清理未完成文件 |

约束：

- 命令层不弹窗、不阻塞、不执行安装包；耗时动作一律返回任务号。
- 更新源、仓库、清单资产名全部走配置（`RDC_UPDATE_SOURCE`、`RDC_UPDATE_REPO`、`RDC_UPDATE_MANIFEST` 或 `config.json`），不改命令签名。
- 默认更新源为公开仓库 `itwuge/RemoteDesktop`，不携带令牌。

## 2. 新增错误码

| 错误码 | 触发条件 |
|---|---|
| `UPDATE_SOURCE_UNREACHABLE` | 清单地址不可达、本地清单缺失或读取失败 |
| `UPDATE_MANIFEST_INVALID` | 清单字段缺失、版本/日期/sha256 非法、缺少当前平台产物 |
| `UPDATE_HASH_MISMATCH` | 下载完成后 SHA-256 与清单不一致；文件删除且拒绝安装 |
| `UPDATE_DOWNGRADE_REJECTED` | 更新源版本低于当前版本；拒绝降级 |

## 3. 更新清单 v2

- 顶层：`schema`、`version`、`release_date`、`notes`、`mandatory`、`min_supported_version`、`assets`。
- `assets[]`：`platform`、`kind`（`installer` / `portable`）、`name`、`url`、`sha256`、`size`。
- 客户端按当前平台与安装/便携形态选择资产；v1 顶层级 `download_url` + `sha256` 继续兼容。
- 六套包命名规范见 `docs/更新与发布.md`。

## 4. 实现与验证

- 新增 `src/rdc/update/source.py`（更新源解析）与 `scripts/publish_release.py`（发布演练）。
- `src/rdc/update/manifest.py` 支持 v2 多平台产物；`service.py` 增加来源解析与形态选择。
- 单测：`tests/test_update.py`，覆盖版本比较、三种源解析、平台/形态选择、v1 兼容、下载校验、降级拒绝、篡改清理、源不可达。
- 端到端：`scripts/e2e_release.py`，本地模拟 Release 结构跑通 tag → 产物 → 清单 → 检查 → 下载 → 校验 → 安装提示。
