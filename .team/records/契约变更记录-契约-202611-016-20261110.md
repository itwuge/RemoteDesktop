## 1. 增量内容

### 1.1 候选类型新增 `mapped`

`docs/design/connect-v1.md` 中 `Candidate.kind` 原取值范围为 `host | srflx | relay`，现新增：

| 取值 | 含义 | 地址来源 | 优先级 |
|---|---|---|---|
| `mapped` | 经路由器端口映射得到的公网入站端点 | UPnP-IGD `AddPortMapping` / PCP MAP / NAT-PMP MAP | 读回校验通过 92；外部探针确认 95 |

语义要点：

- 仅在「映射成功 + 外部地址为公网 + 与 STUN 反射地址一致 + 条目读回指向本进程内部端口」同时成立时才产生候选；任一不满足即不产生候选，只保留原因。
- 优先级位于 srflx(90) 与 v6 host(100) 之间，高于 v4 host(80)；仅影响排序与展示，不改变打洞「逐个候选都试」的既有行为。
- 同出口（两端公网候选同一地址）时 `mapped` 与 `srflx` 一并剔除：实测小米路由器 HD R3D 不支持 hairpin，内网回连公网映射地址必然失败，不能据此判定打洞失败。

### 1.2 新增映射失败原因码

以下原因码当前只出现在连接层日志与 `connect.mapping` 返回结构中，不进入命令层返回包络，因此**未**并入 `src/rdc/core/errors.py`：

| 原因码 | 触发条件 | 用户可读文案 |
|---|---|---|
| `MAPPING_UNSUPPORTED` | 未发现默认网关上的 IGD，且 PCP/NAT-PMP 均不可用 | 没有可用的端口映射通道（未发现 IGD，NAT-PMP/PCP 也不可用） |
| `MAPPING_REJECTED` | `AddPortMapping` 被路由器拒绝（如 718 ConflictInMappingEntry） | 路由器拒绝了端口映射请求 |
| `MAPPING_LEASE_FAILED` | `AddPortMapping` 返回成功但条目读回不一致，或续租失败 | 端口映射租约未能建立或读回不一致 |
| `MAPPING_EXTERNAL_MISMATCH` | 外部地址非公网，或与 STUN 反射地址不一致 | 路由器外部地址与 STUN 反射地址不一致（多层 NAT 或 CGNAT），映射不可作为直连候选 |
| `MAPPING_EXTERNAL_UNREACHABLE` | 注入的外部探针确认端口不可达 | 映射端口在外部探测中不可达 |

内部辅助原因（不作为错误码对外）：`mapping_disabled`、`mapping_no_gateway`、`mapping_lease_expired`、`mapping_pcp_fallback`。

### 1.3 `connect_level_result` 的 p2p 级 detail 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `mapped_candidates` | int | 本次参与候选交换的 `mapped` 候选数，无映射时为 0 |
| `hairpin_blocked` | bool | 仅在判定同出口且因此剔除全部公网候选时出现 |

两者均为附加字段，既有 `mapping` 字段与取值（`eim` / `symmetric` / `unknown`）不变。

## 2. 兼容性

- 候选与结果结构只增加字段与枚举值，旧读取方按未知 kind 忽略即可，不改变既有 `host`/`srflx`/`relay` 语义。
- 信令侧 `candidate` 交换结构不变，`kind` 为字符串，服务端无需感知新取值。
- 端口映射默认开启，可通过环境变量 `RDC_PORT_MAPPING=off` 关闭；关闭后行为与本次变更前完全一致。

## 3. 安全与卫生约束

- 只映射 UDP；外部端口从 49152 以上随机选取，不使用 1024 以下端口。
- 申请前读回目标端口，若已被其它内部端点占用则换端口，不覆盖他人规则；删除只删本次创建且读回仍指向本进程内部端口的条目。
- 租期默认 120 s，会话期间按租期一半续租；连接流程结束、最后一个会话结束、进程正常退出都会删除映射；异常退出（含强杀）依赖租期自然过期兜底，不保证即时清理。
- 只接受来源 IP 等于默认网关的 IGD；局域网存在第二个 IGD 且未显式指定网关时拒绝猜测。

## 4. 验证路径

单测 `tests/test_connect_mapping.py`（37 项，全部使用伪造 IGD 响应与注入桩，不发出真实网络包）覆盖：

1. 设备描述解析与相对 controlURL 归一；
2. 只信任默认网关、双 IGD 时拒绝猜测、无应答返回空；
3. 映射成功、读回不一致、718 拒绝保留 SOAP 错误码、已占用端口不覆盖；
4. 续租（条目丢失后重发）、租约到期判定、失败映射续租为空操作；
5. PCP 失败回退 NAT-PMP、PCP 成功、固件回 `version=0` 时判不支持；
6. NAT-PMP 请求报文格式与应答解析；
7. 删除幂等、租约关闭幂等、全局清理只删一次；
8. 外部地址与 STUN 不一致、CGNAT 地址、外部探针通过/失败；
9. 候选并入 `collect_candidates`、同出口剔除、对称型 NAT 有映射时仍打洞。

真机脚本 `scripts/verify_port_mapping.py` 直接调用产品代码，按「发现 → 外部地址 → STUN 对比 → 申请 → 读回 → 续租 → 删除 → 复验」输出证据 JSON，只动本次申请的外部端口。
