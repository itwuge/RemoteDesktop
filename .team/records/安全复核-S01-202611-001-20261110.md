# 安全复核-S01-202611-001-20261110

| 字段 | 内容 |
|---|---|
| 复核岗位 | S01 安全审查 |
| 日期 | 2026-11-10 |
| 复核对象 | 契约 v1.2（账号、绑定、授权、申请制）与 v1.3（免确认、屏幕墙）及对应实现 `src/rdc/accounts/`、`src/rdc/wall/` |
| 结论口径 | 区分「设计层结论」「实现层结论」「未验证」；未验证不得写成通过 |
| 关联 | 契约-202611-003、契约-202611-004、V1 里程碑划分 |

## 一、复核范围

1. 越权控制：非所有者能否审批、改免确认开关、读审计、解绑他人设备。
2. 授权绕过：范围（scope）是否被放大、一次性授权是否可重复使用、撤销是否即时。
3. 令牌重放：设备令牌与会话令牌的摘要存储、有效期、吊销路径与重放窗口。
4. 审批伪造：审批主体校验、申请与授权的绑定关系、拒绝是否留痕。
5. 合规：账号体系涉及的用户数据存储，单列一条。

## 二、逐项结论

### 2.1 越权控制

| 攻击路径 | 设计约束 | 实现现状 | 结论 |
|---|---|---|---|
| 非所有者审批 / 拒绝 | 仅设备所有者或被控端本机可审批（`_can_approve`） | 已实现：所有者或会话绑定的设备侧；其他账号返回 `PERMISSION_DENIED` | 设计通过；实现通过（内存模型） |
| 非所有者改免确认开关 | 仅所有者可改 | 已实现并进审计 `trust_policy.change` | 通过 |
| 非所有者读审计 | 仅所有者或被控端本机 | 已实现，非所有者返回 `PERMISSION_DENIED` | 通过 |
| 解绑他人设备 | 仅所有者 | 已实现 | 通过 |
| 未登录调用账号命令 | 一律拒绝 | 已实现，统一 `CREDENTIAL_INVALID` | 通过 |
| 绑定他人已绑定设备 | 拒绝 | 已实现，返回 `PERMISSION_DENIED` | 通过 |

遗留：当前为单进程内存实现，无并发锁；多线程或服务端部署时必须加锁与事务化，否则存在检查与写入之间的竞态（记为 R-1，未验证）。

### 2.2 授权绕过

| 攻击路径 | 结论 |
|---|---|
| 用小范围授权执行大范围操作 | `find_active_grant` 只匹配 `scope` 相等或 `full`；低范围不能放大执行 | 通过 |
| 重复使用一次性授权 | 使用时立即写 `used_at`，`active` 即变假 | 通过（单线程） |
| 撤销后继续使用 | `revoked_at` 立即生效，`active` 为假 | 通过 |
| 转让未被允许的授权 | `transferable` 字段存在，但 v1.3 未提供服务端转授命令；转授能力当前**未实现**，不得宣称支持 | 未验证 |
| 伪造授权 ID | 授权由服务端生成 UUID，非客户端拼造；当前无外部接口，风险低 | 通过（内存） |

### 2.3 令牌重放

| 项 | 结论 |
|---|---|
| 存储 | 令牌只存 SHA-256 摘要，明文只在签发时返回一次 | 通过 |
| 有效期 | 设备令牌 30 天、会话令牌 15 分钟；过期返回 `TOKEN_EXPIRED` | 通过 |
| 吊销 | 解绑、改密、主动吊销立即置 `revoked_at`，会话计数并记录 `session.kicked` | 通过 |
| 重放窗口 | 当前令牌未绑定来源 IP、设备指纹或一次性 nonce；有效期内被窃取即可重放 | **风险 R-2（中）**：接入真实网络前必须由 TLS 1.3 通道承载，并在信令层给令牌绑定 `device_id` 与会话随机数；本轮未实现绑定，记为未验证 |
| 传输 | 账号命令当前只在本地进程内调用，无网络暴露 | 未验证（待接服务端） |

### 2.4 审批伪造

| 项 | 结论 |
|---|---|
| 审批主体 | 已校验所有者或设备本机；申请不存在返回 `REQUEST_NOT_FOUND` | 通过 |
| 申请与授权绑定 | 授权由申请记录生成，`device_id`、`requester`、`scope` 取自申请，不接受客户端覆盖 | 通过 |
| 重复审批 | 非 `pending` 状态拒绝 | 通过 |
| 拒绝留痕 | 写 `access.reject` 审计并保留理由 | 通过 |
| 审批消息签名 | 信令侧审批消息尚未定义签名与防重放字段；当前为本地命令，无伪造入口 | **未验证**：接入信令前必须补签名与时间戳窗口，否则存在伪造审批风险 |
| 时间窗口 | 申请 24 小时未处理置 `expired`；授权有效期上限 7 天 | 通过 |

### 2.5 屏幕墙

| 项 | 结论 |
|---|---|
| 4K60 并发 | 实现层断言 `MAX_CONCURRENT_4K60 = 1`，聚焦时只提升一格 | 通过（设计层硬约束） |
| 预算绕过 | 布局切换与聚焦均重算预算，越界返回 `WALL_BUDGET_EXCEEDED` | 通过 |
| 预览流鉴权 | 契约要求预览复用会话令牌校验；实现层尚未接真实会话 | 未验证 |
| 降级顺序 | 减格 → 降预览 → 暂停未聚焦格，顺序由纯函数固定 | 通过 |

## 三、风险清单

| 编号 | 风险 | 等级 | 缓解 | 状态 |
|---|---|---|---|---|
| R-1 | 内存实现无并发锁，检查与写入存在竞态 | 中 | 接持久层时加事务与乐观锁；服务端单写通道 | 未修复，待持久层 |
| R-2 | 令牌未绑定来源，有效期内可重放 | 中 | TLS 1.3 通道 + 令牌绑定 device_id 与会话随机数 + 短有效期 | 未实现，接入网络前必须完成 |
| R-3 | 审批消息无签名与时间戳 | 中 | 信令层补 `sig` 与 5 分钟窗口，服务端拒绝重复 | 未实现 |
| R-4 | 授权转授能力未实现 | 低 | 文档与界面不得宣称支持转授；`transferable` 仅作字段预留 | 已标注 |
| R-5 | 审计仅内存、可被进程重启清空 | 中 | 接持久层并只追加，禁止更新与删除历史事件 | 未实现 |
