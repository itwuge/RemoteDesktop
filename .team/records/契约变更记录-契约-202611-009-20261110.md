## 1. 屏幕墙聚焦与预览消息（protocol-v1 v1.4）

| 消息 | 方向 | 必填字段 | 说明 |
|---|---|---|---|
| `wall_focus` | 控制端 → 信令服务 | wall_id、cell | 申请聚焦名额；全局只允许一块墙聚焦 |
| `wall_focus_granted` | 信令服务 → 控制端 | wall_id、cell、focus_token、expires_at | focus_token 同时用于该路数据面接入，TTL ≤ 300 秒 |
| `wall_unfocus` | 控制端 → 信令服务 | wall_id | 退出聚焦；幂等 |
| `wall_unfocused` | 信令服务 → 控制端 | wall_id、released | released=false 表示原本未持有 |
| `wall_preview` | 控制端 → 信令服务 | wall_id、cell | 申请预览令牌；同格重签即吊销旧令牌 |
| `wall_preview_granted` | 信令服务 → 控制端 | wall_id、cell、preview_token、expires_at | 60 秒有效，绑定墙、格、账号与设备 |
| `wall_preview_revoked` | 信令服务 → 控制端 | wall_id、cell、reason | 墙关闭、重签或失效时推送 |

硬约束：

- 身份取自已认证连接，不得由 payload 自报账号；服务端只签发凭证，预算与格号校验仍归命令层（30、45、47 条）。
- 令牌只出现在两个 granted 消息中，不得进日志、审计详情与界面文案。
- 收到 `wall_preview_revoked` 后必须停止使用旧令牌；过期按 `PREVIEW_TOKEN_INVALID` 处理并重新申请。

## 2. presence 接线

- `RelayServer` 新增可选 `presence_sink`，默认接 `accounts.record_presence`（进程内账号服务）；跨进程部署由装配处注入共享存储实现。
- 回归：`test_presence_sink_feeds_accounts_list_devices` 覆盖登录设备上线后 `list_devices` 返回 `presence_state=online`、`online=true`，下线后返回 `offline`。
- 未接线或未登录时仍返回 `unknown`，不得伪造在线。

## 3. 数据面 from_device_id（202611-001 第 3 项）裁决

**接受现状并关闭**：

- `relay_token` 已绑定 `session_id` 与设备标识，中继按令牌解析对端，V1 每条数据面会话严格为 1:1 发布/订阅，接收方由会话配对即可确定发送方。
- 数据面内容是端到端 AEAD 密文，由中继向帧头注入明文字段会破坏“只转发密文与最少元数据”的边界；由客户端自报又会变成不可信输入。
- 信令路由消息的 `from_device_id`、`to_device_id` 保留为可选提示字段，投递以连接身份与 `session_id` 为准，不作鉴权依据。
- 重开条件：引入 N:1 分屏扇出、跨账号归因或中继审计需要发送方时，按 v2 增补字段与校验规则。
