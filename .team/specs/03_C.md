# 03 C 细则

## 1. 文件名头要求

- `.c` 与 `.h` 文件首部用 `/* */` 块注释 banner, 首行 `@file`。
- 八栏映射: 「文件」栏与「文件用途」栏分别写 `@file` 与 `@brief`, 其余六栏逐行以 `字段名: 内容` 书写。
- 头文件 banner 之后必须紧接 include guard 或 `#pragma once`, 二者取其一; banner 内不重复声明保护方式。
- 禁止在 banner 写作者、日期、修改记录、版权声明以外的装饰边框文字。
- 一个文件一个主要职责; 「文件用途」栏一句话写不下, 说明职责已超载, 应拆分。

## 2. 依赖引入区要求

- 顺序固定: 对应头文件 -> 标准库 -> 第三方 -> 项目内, 组间空一行。
- 每个 `#include` 行尾注释来源与用途; 系统头文件用 `< >`, 项目头文件用 `" "`。
- 头文件必须自包含: 单独编译应可通过, 缺什么就引入什么, 不允许依赖调用方先引入。
- 禁止 `#include` 实现文件(`.c`); 禁止在头文件中定义变量与函数体。
- 条件引入写 `#if defined(...)`, 并在上一行注释说明生效平台与关闭后的替代路径。
- 禁止为凑齐声明引入整包头文件, 能用前置声明解决的不用 `#include`。

## 3. 类型与函数注释要求

- Doxygen 风格, 逐项写全: `@brief` 一句话用途, `@param[in]` / `@param[out]` / `@param[in,out]` 逐参数, `@return` 返回值, `@retval` 具体取值含义, `@note` 约束与副作用, `@warning` 调用方必须知道的风险。
- 每个导出函数、结构体、枚举、宏、typedef 都必须注释; 结构体逐字段注释, 枚举逐成员注释。
- 内存归属必须写清: 返回指针的函数写 `@note 所有权: 由被调用方分配, 调用方用 xxx_free 释放`; 传入指针写明调用方是否保留、函数是否接管、是否可传 NULL。
- 含多个公开函数的类型或模块, 在 `@brief` 之后写「方法一览」, 形式为每行 `@par 方法一览` 小节内的 `pick(name, response, default) -> type: 一句话用途`; 仅作速查, 参数与错误说明写在各自函数注释里。
- 必须写「为什么」: 参数为何可空、返回值为何可能是负数、为何用哨兵值而不是错误码、为何不做越界检查。
- 禁止用 `@param` 复述参数名; 禁止 `@return` 只写「返回值」。

## 4. 行尾注释判据

- 只写原因不写翻译; 判据同总则。
- 本语言必写情形:
  - 未定义行为规避, 如清零、对齐、边界钳制的原因。
  - 位运算、掩码、偏移常量的来源。
  - 指针所有权转移点与释放责任。
  - `#ifdef` 平台分支的理由与另一分支的差异。
  - 有意不做校验的理由; 无理由必须补校验。
- 免写情形: 字段名自解释的赋值、无后果的 `return 0`。
- 裁定结果按总则写入本节, 以案例沉淀。

## 5. 分区标记

- 形式: `/* =========** 名称 =========** */`。
- 标记下一行必须是该分区首行的 Doxygen 注释或一行职责注释; 标记本身不写职责说明。
- 分区顺序: 宏与常量 -> 类型 -> 静态函数 -> 公开函数 -> 测试钩子。
- 头文件中分区顺序: guard -> 引入 -> 宏与常量 -> 类型 -> 原型声明 -> 内联函数。

## 6. 标点与空格

- 注释内标点一律半角; 中文与英文或数字之间留一个空格。
- Doxygen 标签后紧跟一个空格, 标签名全小写。
- 全角标点只允许出现在面向用户的字符串字面量或日志格式串内。

## 7. 违规范例(一条)

```c
/* 不合格示例: 无 banner, 返回裸指针不写归属 */
static char *dup_name(const char *src);
```

问题:

- 缺 `@file` / `@brief` 文件头与八栏。
- 返回裸指针未写谁分配谁释放。
- 未说明 `src` 是否可传 NULL、返回值是否可能为 NULL。

## 8. 交付前自检清单

- [ ] 每个 `.c` / `.h` 都有 banner, 八栏齐全, `@file` 与 `@brief` 存在。
- [ ] 头文件有 include guard 或 `#pragma once`。
- [ ] `#include` 分组正确, 每行注明来源与用途。
- [ ] 头文件可单独编译通过。
- [ ] 导出函数与类型均有 Doxygen 注释, 内存归属写明。
- [ ] 含多个公开函数的模块写了「方法一览」。
- [ ] 行尾注释只写原因。
- [ ] 分区标记统一, 编译告警为零。
